다음 파이썬 3 프로그램의 출력 전체를 줄 순서대로 정확히 쓰시오. 또한 **원소 조건을 행의 최댓값 위치 조건으로 변경**에 해당하는 중간 상태나 분기 근거를 제시하여 결과를 설명하시오.

```python

total = 0

    if row[0] != max(row):
        total += max(row) - min(row)
print(total)
```
