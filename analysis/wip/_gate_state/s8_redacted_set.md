**25.** 다음 프로그램의 실행 결과를 쓰시오. (4점) `[IN-22 · T4 · DF1·DF2·DF5 · E5]`

```
a = [[2, 9, 4],
     [7, 1, 8],
     [5, 6, 3]]
total = 0
for i in range(3):
    for j in range(3):
        if i != j and a[i][j] % 2 == 1:
            total = total + a[i][j]
print(total)
```

> **채점 조건**: 4점, 부분 점수 없음. 정수 하나만 쓴다.

**26.** 다음 프로그램이 실행되는 동안 변수 `i`와 `s`의 값 변화를 표로 정리한 것이다. 물음에 답하시오. (4점) `[IN-26 · T3 · DF1·DF2 · E5]`

```
s = 1
for i in range(2, 6):
    if i % 2 == 0:
        s = s * i
    else:
        s = s + i
print(s)
```

| 반복 회차 | `i` | 반복이 끝난 뒤의 `s` |
|---|---|---|
| 1회 | 2 | 2 |
| 2회 | 3 | (가) |
| 3회 | 4 | (나) |
| 4회 | 5 | (다) |

(1) (가), (나), (다)에 알맞은 값을 쓰시오.
(2) `s`가 **곱셈으로 갱신된** 회차의 `i` 값을 모두 쓰시오.

> **채점 조건**: (가)·(나)·(다) 각 1점, (2) 1점. (2)는 두 값을 모두 써야 정답으로 한다.
