## 유형 SM2-04: 직선·연장선 위의 점 — 길이 비로 결정 (외분 우회 설계)
- 상태: 검증(부교재) / 중요도: ★★
- 영역/단원: I-1 평면좌표
- 출제 빈도: #1-8, #1-9 (2문항)
- 패턴: 방향 성분 AB=(Δx, Δy)의 **실수배**로 점을 잡아 길이 비 조건을 만족시킨다.
  **해의 개수를 발문이 통제**한다 — "직선 위"면 양방향 2해, "연장선 위 + 부호 단서"면 1해.
- 변형 축: 비 계수(3:2 ↔ 2:3 ↔ 무리수 비) / **"직선 위"↔"선분 위"↔"연장선 위"(해의 개수 조절)** / 목표(x+y의 최대·최소 ↔ 좌표 ↔ 두 해 사이 거리) / 기준점(B↔A) / 배율 k배
- 사용 용어·공식: C = B ± k·(Δx, Δy) / AB = √((Δx)²+(Δy)²)
- 함정 요소: **"직선 AB 위"는 2해**인데 한쪽만 구함(문제가 최대·최소를 물어 2해를 강제) / 3AB=2BC를 뒤집어 BC=(2/3)AB로 씀 / 좌표 차를 그대로 3배 하는 비례 계수 오류 / 외분 공식으로 억지 변환하다 부호 오류
- 대표 예시: #1-8 직선 AB 위 3AB=2BC → x+y의 M, m / #1-9 연장선 위 3AB=BC, a>0 → C(22,15)
- 금지·주의: **이 유형이 외분의 교육과정 정합 대체재다.** 외분 문항을 만들고 싶으면 이 형태로 쓴다.
- 이력: 260822 등록

## 유형 SM2-05: 중점의 활용 — 사각형의 성질
- 상태: 검증(부교재) / 중요도: ★★
- 영역/단원: I-1 평면좌표
- 출제 빈도: #1-4, #1-14, #1-15(증명) (3문항)

- 변형 축: 둘레↔넓이 / 사각형 종류(일반↔평행사변형↔마름모↔직사각형) / 중점↔삼등분점 / 대각선 하나만 주고 역추적 / 목표식(a³+b³ ↔ a²+b² ↔ |a−b|) / 꼭짓점 순서 교란(ABDC) / 증명↔"보이고 그 좌표도 구하시오" 혼합
- 사용 용어·공식: 중점 공식 / 중점연결정리 PQ=½AC / 평행사변형 ABCD ⇔ AC의 중점 = BD의 중점
- 함정 요소: **꼭짓점 순서 ABCD에서 대각선은 AC·BD** — AB·CD로 잘못 짝지음(최다 오답) / 둘레를 ½(AC+BD)로 계산(각 대각선의 절반이 2변씩이므로 합은 AC+BD) / 미지수가 곱(ab) 형태로 주어지면 개별 값을 구하려 들지 말고 대칭식으로 / 증명에서 **좌표를 특수값으로 잡아 일반성 상실**
- 대표 예시: #1-4 중점 사각형 둘레 11√2 / #1-14 평행사변형 → a³+b³=72 / #1-15 PQ·RS 중점 일치 증명
- 금지·주의: 증명 문항은 결론 문장("따라서 일치한다")을 명시하게 채점 기준을 잡는다.

## 유형 SM2-06: 무게중심 — 좌표와 면적 분할
- 상태: 검증(부교재) / 중요도: ★★
- 영역/단원: I-1 평면좌표
- 출제 빈도: #1-11, #1-12, #1-13 (3문항)
- 패턴: G = 세 꼭짓점 좌표의 평균. 정삼각형에서는 **G = 외심**이라 AG = 외접원 반지름 R = a/√3.
  무게중심은 삼각형을 **넓이가 같은 3조각**으로 나눈다.
- 변형 축: 주어진 것(G의 좌표 ↔ 외심 ↔ 한 변의 중점 ↔ AG의 길이) / 묻는 값(한 변↔넓이↔외접원 넓이) / 정삼각형↔이등변↔정사각형·정육각형 / 넓이 대상(ABG↔ABC) / 무리수 제거 계수(16S²↔S²↔3S) / 선형결합 계수(a+4b↔3a+3b)
- 사용 용어·공식: G=((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3) / 정삼각형 R=a/√3 / 넓이 (√3/4)a²
- 함정 요소: **R을 a/2(외접원↔내접원)나 a/(2√3)(내심)와 혼동** / △ABG는 전체의 **1/3**(1/2·1/6 아님) / G의 좌표가 분수로 나오는데 묻는 계수가 분모를 상쇄하도록 설계돼 있어 대충 하면 어긋남 / B, C 좌표를 굳이 구하려는 우회
- 대표 예시: #1-11 AG=2√2 → 한 변 2√6 / #1-12 16S²=243 / #1-13 등거리 점 → G → a+4b
- 금지·주의: (없음)

## 유형 SM2-07: 세 점의 공선·두 점을 지나는 직선의 결정
- 상태: 검증(부교재) / 중요도: ★★
- 출제 빈도: #2-1, #2-6 (2문항)
- 패턴: 기울기 상등으로 공선 조건 → 미지수의 이차방정식 → **근과 계수의 관계로 "모든 k의 합"**
- 변형 축: 문자 위치(좌표 1개↔2개) / 목표(합↔곱↔최댓값) / 구하는 대상(길이↔넓이↔기울기)

- 변형 축: 대칭축(원점↔y=x↔y=−x) / 정점 좌표 자체 묻기 / 두 원이 접할 조건 / 넓이비 값
- 함정 요소: **대칭이동을 하지 않고 원래 식에서 정점을 구함**(순서 오류) / 두 중심 사이 거리는 중심 벡터의 **2배** / **닮음비 = √(넓이비)** / AA′ 길이의 √2 계수
- 대표 예시: #4-15 원점 대칭 후 k 정점 / #4-18 y=x가 넓이 이등분 → a=b / #4-21 닮음 넓이비 9:4 (T3~T4)
- 이력: 260822 등록

## 유형 SM2-31: 이동의 합성 역추적 · 방정식으로 표현
- 상태: 검증(부교재) / 중요도: ★★
- 출제 빈도: #4-14, #4-22 (2문항)
- 패턴: 평행이동과 대칭이동을 합성한 결과를 주고 원래 식을 역추적하거나,
  **f(x,y)=0 꼴로 이동을 표현**한다. 도형을 옮기면 **식에는 반대 부호**가 들어간다.
- 변형 축: 이동 방향 뒤집기 / 순서 뒤바꾸기 / 대칭축 교체 / f로 g를 표현↔g로 f를 표현
- 함정 요소: **합성 순서를 뒤바꿈**(대칭을 먼저 적용) / x축 대칭에서 y→−y 부호 / 식 표현의 반대 부호
- 대표 예시: #4-14 평행 후 x축 대칭 역추적 / #4-22 f(x−5, −y−1)=0 (T3~T4, 답이 수치가 아닌 식)
- 금지·주의: #4-22처럼 **답이 식인 문항**은 서술형으로 배치한다.
- 이력: 260822 등록

## 유형 SM2-32: 임의의 직선 y=mx+n에 대한 대칭이동
- 상태: 검증(부교재) / 중요도: ★★ / ⚠️ **교육과정 명시 범위 초과 — 부교재 근거로 출제**
- 출제 빈도: #4-19, #4-20, #4-23 (3문항)
- 패턴: **① 두 점의 중점이 대칭축 위에 있다 + ② 두 점을 잇는 선분이 대칭축과 수직이다**
  → 이 두 조건을 연립한다. 부교재는 같은 두 조건을 **3방향으로 요구하는 난이도 사다리**를 쓴다:
  1. 상(像)을 주고 **원상을 역추적**(#4-19)
  2. 두 점만 주고 **대칭축 자체를 구함**(= 수직이등분선) (#4-20)
  3. **원의 중심만 대칭**시킨 뒤(반지름 불변) **y축 대칭을 합성**(#4-23)
- 변형 축: 대칭점 방향 뒤집기 / 직선 방정식을 미지수화 / 넓이↔둘레 / 대칭 순서 뒤집기 / 직선 대칭만 단독 출제 / l이 지나는 점 조건 추가
- 함정 요소: **두 조건 중 하나(특히 수직 조건) 누락 — 최대 오답원** / 수직 기울기 −1/m의 부호 / 답이 분수 좌표 / 절편이 음수라 넓이에서 절댓값 / **마지막 합성(y축 대칭)을 잊음** / 반지름은 대칭이동에서 불변
- 대표 예시: #4-19 A(19/5,−2/5) 역추적 / #4-20 l = AB의 수직이등분선 → 축과의 넓이 ¼ / #4-23 (x+2)²+y²=1
- 금지·주의: 성취기준 [10공수2-01-07]은 대칭 대상을 원점·x축·y축·y=x로 한정한다.
  이 유형을 출제할 때는 근거를 **"부교재"** 로 명기한다. 자세한 사정은 `../curriculum_2022.md` 🚧 2번.
- 이력: 260822 등록

## 유형 SM2-33: 대칭점을 이용한 최단거리
- 상태: 검증(부교재) / 중요도: ★★★ (4문항 — **시트 #4의 킬러 축**)
- 출제 빈도: #4-12, #4-13, #4-16, #4-17 (4문항, 이 중 T4가 2문항)
- 패턴: 한 점을 축 반대편으로 **대칭이동**시켜 경로를 펴고 직선거리로 환원한다.
  고급형에서는 (a) **원 위의 자유점을 중심±반지름으로 치환**, (b) **고정 길이 변을 분리**한 뒤 나머지만 최소화한다.
- 변형 축: 대칭축(x축↔y축↔y=x↔일반 직선) / 최솟값↔최댓값↔차 / 넓이·둘레 결합 / 내분비 변경 / 원의 안팎 위치 / P를 다른 변 위의 점으로 / 삼각형 둘레↔사각형 둘레
- 사용 용어·공식: AP = A′P (A′는 대칭점) / 세 점 일직선일 때 최소 / 원 위의 점 B에 대해 BP ≥ CP − r
- 함정 요소:
  - **고정된 변을 함께 최소화하려 함** — #4-16에서 SP=2√5는 이미 고정이고 나머지만 최소화 대상
  - **어느 점을 어느 변에 대칭시킬지** 선택 실패
  - **반지름 가감을 잊음**, 그리고 결과가 `a+b√2` 꼴일 때 **a가 음수**(−2)
  - 최솟값만 구하고 **"그때의 점 P"** 를 안 구함(넓이까지 요구하는 문항)
  - "CD를 1:4로 내분"의 기준점(C에서 시작)
- 대표 예시: #4-16 직사각형 내접 사각형 둘레 최소 6√2+2√5 (T4) / #4-17 x축 + 원 위 자유점 → 4√2−2, ab=−8 (T4)
- 금지·주의: 이 유형이 **시트 #4에서 가장 배점이 클 가능성이 높다.** 세트에 T4로 반드시 포함.
- 이력: 260822 등록

## 배열 문법 — 출제자가 문항을 늘어놓는 방식 (260823 신설)

> 유형·빈도와 별개로, **문항이 어떤 순서로 배치되는가**도 시험지 예측 정보다.
> 전사본 93문항의 배열을 다시 훑어 아래 3가지를 확인했다.

1. **교과서 진도 순서대로 배열하고, 난이도는 그 안에서 오르내린다(톱니).**
   시트 #4는 평행이동(#1~9) → 대칭이동(#10~23) 순이고, 시트 #3은 원의 결정 → 축에 접하는 원 →
   위치 관계 → 접선 → 두 원 순이다. 난이도는 단조 증가가 **아니다** — 시트 #2는
   T1이 4·12·21번으로 흩어져 있고 T4는 14·17·19·20번으로 **후반 절반에 몰린다**.
   → 세트를 만들 때 **T1을 앞에만 몰지 말고**, 킬러는 후반부에 배치한다.

2. **같은 소주제를 2~5문항 연속 블록으로 묶어 반복 훈련시킨다.** 이 시트의 기본 문법이다.
   - #3-4·5·6·7 — 축에 접하는 원 **4연속**(부호 케이스 분류를 반복 숙달시킴)
   - #3-29~32 — 두 원 공통접선 **4연속**(그중 30·31·32가 동일 골격 3연작)
   - #4-19·20·23 — 임의 직선 대칭의 **3단 사다리**(원상 찾기 → 대칭축 찾기 → 도형+합성)

   → 3연작은 SM2-24의 특수 사례가 아니라 **이 출제자의 일반 문법**이다.
     새 세트도 주력 유형은 단발로 흩지 말고 **연속 블록 + 각도 변형**으로 배치한다.

3. **증명은 평면좌표 단원 전용이고, 시트의 마지막 문항에 놓인다.**
