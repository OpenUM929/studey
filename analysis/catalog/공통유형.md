# 공통 유형 — 전 과목 공통 출제 문법·형식 (정본)

> 상산고 1학년 1학기 지필평가에서 **과목을 가로지르는 공통 출제 관행**. 문제 생성 시 이 규칙을 먼저 적용하고,
> 과목별 카탈로그의 세부 유형을 얹는다. (CLAUDE.md 원칙 8: 공통 유형 분류)

## C-00: 시험지 공통 형식 (전 과목)
- 표지: "상산고등학교 / 제1학년 / OO과 제1학기 (중간|기말)고사 문제지 / 20XX년 X월 X일 X교시".
- 안내: 총 X쪽, 선택형 N문항 + 서답형/서술형 M문항, 배점 각 문항 끝 표기.
- 반영 비율: **중간 30% + 기말 30% + 수행평가 40%** (전 과목·전 회차 공통).
- 필기구 규정: 검정·청색 펜(과목따라 연필 허용). 서답형 별도 답안지 또는 OMR 뒷면.
- 저작권 문구 하단 고정.
- **하단 페이지 표기**: "[ 전체 N면 중 k면 ]".

## C-01: ㄱㄴㄷ <보기> 합답형 (최강 공통 유형)
- **통합과학·통합사회·한국사**의 주력. (영어·국어는 적고, **수학은 0건** — C-09 참조)
- 구조: 자료(글/그림/표/그래프) 제시 → <보기> ㄱ,ㄴ,ㄷ(ㄹ) → "있는 대로 고른 것"을 ①~⑤ 조합으로.
- 배점: 자료 복잡도·보기 수에 비례(과학 2.2~4.0, 사회 2.3~4.4).
- **함정 설계 공통 문법**:
  - 정반대 진술(반비례/무관/역방향)로 매력적 오답.
  - "모두/항상/반드시/~만" 등 극단 한정어로 참을 거짓으로.
  - 부분참(ㄱ만 옳고 ㄴ은 미세 왜곡).
- 변형 생성 시: 참 보기 1~2개 + 미세 왜곡 오답 1개 + 정반대 오답 1개 배치.

## C-02: 자료 제시형 (비주얼 리터러시)
- 전 과목 공통. 그래프(과학 v-t·기후, 수학 함수, 영어 통계), 표(조성비·특징 유무), 지도(사회·한국사), 그림·모형(과학 결합모형·세포, 한국사 문화유산).
- 발문 공통: "옳은 것 / 옳지 않은 것 / 있는 대로 / 가장 적절한 것".
- **"옳지 않은 것 2가지 고르기"** 복수 정답형도 공통(사회·한국사).

## C-03: 자료 판별형 (순서 없이 제시 → 무엇인지 맞히기)
- 과학(원소 질량비 가·나, 소기관 A~C, 삼투/촉진확산 I·II), 사회(기후 그래프 가~다), 한국사(㈎ 시대·왕).
- "순서 없이 나타낸 것"이라는 표현이 신호. 단서로 대상 확정 후 세부 판단.

## C-04: 학생 대화·평가지 채점형
- 과학(학생 A~C 발표 옳은 사람), 사회(갑~무 √ 체크표, 형성평가지 예/아니요), 한국사(교사–학생 문답).
- 여러 진술 중 **모두 옳게 표시한 주체** 고르기 → 1칸만 틀려도 탈락(정밀 판단 요구).

## C-05: 서답형·서술형 (채점 조건 명시)
- 전 과목 공통. **채점 단서를 발문에 명시**하는 것이 상산고 특징:
  - "정확한 용어/명칭 사용 시만 정답"(사회 헌법 용어, 한국사 명칭·정자체).
  - "주어+서술어 갖춘 완결 문장"(사회 실업률).
  - "○음절 단어 ○개"(국어), "차별성 안 드러나면 감점"(국어).
  - "관계대명사/수동태 반드시 포함, 제시 어휘만"(영어 조건 영작).
  - "풀이 과정 서술"(수학·과학).
- 부분 점수 배분 표기. **변형 문제 생성 시 이 채점 조건을 반드시 재현**.

## C-06: 실생활·융합 소재
- 과학(세탁기 제원표·스마트윈도·범퍼카), 사회(피자·축제·근로계약), 영어(쇼핑카트·가뭄 대응).
- 개념을 실생활 맥락에 이식 → 적용력 평가. 변형 시 소재만 교체 가능.

## C-07: 배점·난이도 상향 경향 (연도별)
- **2024 → 2025~2026 배점 상향**: 과학 2.2~2.8 → 3.0~4.0, 사회 유사, 수학 2.7~4.2.
- 문항 수 유지, 문항당 변별력·자료 복잡도 상승. **현행(2026) 기준 난이도로 생성**.

## C-08: 2022 개정 교육과정 신설 요소
- **과학**: '과학의 기초'(측정·SI 단위·정보통신), '신소재·반도체'가 2025부터 신설 출제.
- **국어**: 공통국어1, **영어**: 공통영어1, **수학**: 공통수학1(행렬 포함), **사회/한국사**: 통합사회1·한국사1 명칭.
- 2024 자료에 없던 영역은 현행 출제 시 반드시 포함 검토.

## C-09: 수학 과목의 예외 관행 (260822 신설 — 1·2학기 공통 확인)

다른 과목의 공통 관행 중 **수학에만 적용되지 않는 것**과, **수학에만 있는 관행**을 분리해 고정한다.

**적용되지 않는 것**
- **선택형·ㄱㄴㄷ 합답(C-01)이 0건.** 공통수학1 기출(2026 중간·기말)과 공통수학2 부교재(93문항)
  **전부 서답형**이다. 수학 문항에 ①~⑤를 만들지 않는다.
- 실생활 융합 소재(C-06)도 드물다. 1학기의 "자투리 천 직사각형 넓이"(SM-09)가 예외적 사례다.

**수학에만 있는 관행**
- **정수 환산 장치**: 답이 무리수·분수로 나오는 문항에서 `a²+b²` `abc` `k²` `16S²` `ab` `m+n√5` 같은
  **정수로 떨어지는 조합값**을 묻는다. 1학기(SM-02·03·05)와 2학기(SM2-06·16·22·24·33)에 걸쳐 일관되며,
  시트 #3에서만 8문항이 이 장치를 쓴다. → 상세는 [출제유형_마스터.md](출제유형_마스터.md) **B13**.
- **발문 종결은 "~을 구하시오"로 통일.** 부교재에 "~은?"이 3건 섞여 있으나 객관식 원출처의 잔재다.
- **그림에 의존하지 않는다.** 그림이 있어도 사분면·부등호 단서가 본문에 있어 그림 없이 성립한다.
  평면좌표 단원은 아예 그림이 0장이다. → [출제유형_마스터.md](출제유형_마스터.md) **A10**.
- **풀이 과정 배점**(C-05)은 그대로 적용된다. 서술형은 결론 문장까지 요구한다.

**260823 보강 — 전사본 재검토로 추가 확인된 것**
- **그림(C-02)은 쓰되 단원이 편중된다.** 공통수학2 93문항 중 그림은 13문항(14%)뿐이고,
  **직선(5)·원(8)에만** 있다. 평면좌표·도형의 이동은 **0장**이다. 즉 수학의 그림은
  C-02의 "자료 제시형"이 아니라 **배치 확인용 보조**이며, 본문 단서만으로 항상 성립한다.
  → 다른 과목처럼 "그림을 읽어야 풀리는" 문항을 수학에 만들지 마라.
- **객관식 원출처 잔재가 5건** 있다(#1-5, #2-10, #3-24, #3-29, #4-21이 "~은?"으로 끝남).
  선지를 떼어내고 재활용한 흔적이다. **재현하지 않는다** — "~을 구하시오"로 통일.
- **답의 형태가 4종**(수치 / 방정식 / 범위 / 개수)으로 갈린다. C-05의 채점 조건은
  형태마다 달라야 한다. → 상세는 [공통수학2.md](공통수학2.md) "답의 형태 축".
- **같은 소주제를 2~5문항 연속 블록으로 배치**해 반복 훈련시키는 것이 수학 부교재의 배열 문법이다.
  (다른 과목에서도 같은 관행이 있는지는 **미확인** — 기출이 들어오면 대조할 것.)

# 변형 문제 생성 표준 절차 (전 과목)
1. 과목 카탈로그에서 **유형 ID** 선택(중요도 ★★★ 우선).
2. 공통유형 C-01~C-06에서 **형식 그릇** 선택.
3. 자료(그림/표/그래프/사료/지문)를 동급 난이도로 새로 구성(원본 복제 금지, 저작권).
4. 함정(C-01 문법)·채점 조건(C-05) 이식.
5. **정답 + 해설 + 근거 유형 ID** 함께 출력(CLAUDE.md 원칙 5).
6. `시연`(기출 미확인) 요소 포함 시 "⚠️ 기출 미확인" 경고(원칙 2).
