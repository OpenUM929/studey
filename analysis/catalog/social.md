# 파트 A: 형식 유형 (F) — 자료 제시·발문 구조

## 유형 F-01: 사상가·입장 비교 (갑·을 / 갑을병정무)
- 상태: 검증 / 중요도: ★★★
- 출제 빈도: 24중간(행복론 갑~무 체크표, 1번), 24기말(정의론 갑·을 1·5번, 분배기준 체크표 4번), 25중간(환경윤리 갑·을 10번, 사상가 14번)
- 패턴: 사상가 주장문 2~5개 제시 → ① <보기> 합답으로 각 입장의 옳은 진술 고르기, 또는 ② 표(관점×학생 갑~무 √표시) 중 **모두 옳게 표시한 학생** 고르기, 또는 ③ 두 사상가가 모두 긍정할 질문 고르기
- 변형 축: 주제(행복론·정의론·분배정의·환경윤리·평화론), 인원(2인 갑을 / 5인 갑~무 체크표), 발문(옳은 진술/공통 긍정 질문/모두 옳은 학생)
- 함정 요소: 한 입장에만 해당하는 진술을 공통으로 오인, 체크표에서 1칸 오답 심기(전부 맞아야 정답)
- 대표 예시: 24중간 1번(에피쿠로스 쾌락→마음의 평온, 체크표), 25중간 10번(생명중심주의 갑 vs 동물중심주의 을)
- 이력: 260714 등록

- 상태: 검증 / 중요도: ★★★ (최빈 형식)

- 변형 축: 지문 소재(소득-행복, 세계화, 인권 판례, 노동), 보기 개수(3~5개), 발문(옳은 것/옳지 않은 것/바르지 못한 것)
- 함정 요소: 반대 극단(반비례·한계 없음), 부분참 진술, "옳지 않은 것 2가지" 복수 정답형
