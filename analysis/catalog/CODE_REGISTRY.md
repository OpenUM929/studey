## 2. 충돌 판정 기록

### F 접두어 이중 소속 (치명도 최상)
- 같은 문자열이 두 과목에서 다른 유형을 가리킨다: `F-03` = 사회 "인물·사상 매칭" ≠ 한국사 "표 자료 시기 순서".
- **인용 규칙(강제)**: 과목 문맥 없이 `F-nn` 단독 인용을 금지한다. 전역 인용은 반드시
  파일 스코프를 병기한다 — `한국사:F-03`, `통합사회:F-02`.
- 원장(TSV·HARVEST_LOG)처럼 ID가 **조인키**로 쓰이는 곳에서는 무조건 스코프를 붙인다.
- 신규 유형에 어느 쪽 파일에서도 새 `F-nn`을 부여하지 않는다(기존 최대번호 연장만 허용).

### 코드 패밀리 간 표기 유사 (혼동 주의)
| 혼동 쌍 | 구분법 |
|---------|--------|
| 관행 `C-07`(공통유형) vs 인지 `C7`(마스터) | 하이픈 유무. **하이픈 있으면 공통유형, 없으면 인지 조작** |
| 함정 `E1~E9`(마스터) vs 종합진단 약점 라벨 `A~E` | 약점 라벨은 리포트 로컬 표기일 뿐 — 표준 약점 식별자는 `WK-nn`(WEAK_LEDGER)이다 |
| 영어 독해 `T-01` vs 난이도 Tier `T2` | 하이픈+2자리 번호면 유형ID, 아니면 티어 |

## 5. 신규 부여 규칙

1. **새 과목**: 2자 대문자 신규 접두어(§3 subject_code와 매핑 행 추가). 기존 접두어·축약 재활용 금지.
2. **같은 과목의 새 학기·단원 세트(수학류)**: `<SM><세트번호>` 연장(SM→SM2→…) 또는 신규 접두어 —
   정할 때 이 등록부에 의미를 남긴다.
3. **영역 세분화(과학류)**: 허용하되 접두어 2자+대문자, 타 과목 접두어와 겹치면 금지.
4. **번호**: 파일 내 1부터 연속, 폐기돼도 결번 보존(재배열 금지).
5. **매체 영역(국어) 예약**(260825, 판정 11-Q3): 공통국어1 매체 유형 신설 시 기존 `K` 접두어 하위 신규 번호로 부여한다. 카탈로그 내 독자 번호 경작 금지 — 다음 갱신 주기에 본 표에 정식 등록(append-only).
6. 부여 전 §1·§2 대조 → 충돌 시 이 문서에 판정을 먼저 기록하고 시작한다.
7. **비가역 선행 등록**(260826, CLAUDE.md 원칙 9-a): 코퍼스ID·유형ID·접두어·subject_code는
   **부여 시점에 되돌릴 수 없다**(운영원칙 ①). 따라서 자료를 정제(REFINE)하기 **전에** 명명 정책을
   이 문서에 먼저 기록한다. "일단 만들고 나중에 정리"는 선택지가 아니다.
   같은 상황에 두 정책(분리 vs 병합)이 공존하면 그 자체를 결함으로 본다.

## 6. 신규 과목·신규 학기 온보딩 — 동시 갱신 목록 (260826 신설)

> 신설 사유: 260826 판정 BF3·BF5 — 정보 과목 신설 계획이 CODE_REGISTRY·DATA_STANDARD만 적었고
> 도구 코드·범위 가드 문서가 빠졌다. 한쪽만 갱신하면 **경고조차 없이 조용히 무시**된다

### 결정 완료 — '2' 과목의 학기 분리 정책 (260826 등록 → 같은 날 사용자 확정, BF2 해소)

수학은 `math1`/`math2`, `SM`/`SM2`로 **분리**된 선례가 있는데, 나머지 과목의 2학기분
(공통국어2·공통영어2·통합과학2·통합사회2·한국사2)을 기존 1학기 카탈로그에 **병합**할지
분리할지가 쟁점이었다(판정 260826_02 BF2). **260826 사용자 확정**으로 아래와 같이 확정하며,
REFINE(S1) 착수 전 기록 요건(원칙 9-a · §5-7)을 충족한다.

- [x] (a) **병합 — 기존 subject_code를 유지한다.** 위 5과목은 커리큘럼상 **같은 과목의
      학기 연속**이므로 `korean`/`english`/`science`/`social`/`history` 코드를 그대로 쓰고,
      학기 구분은 코퍼스ID 회차코드가 담당한다(`EX-korean-20252M`). 카탈로그 파일도 과목당
      1개를 유지한다. 수학의 분리 선례는 **"커리큘럼상 별개 과목(공통수학1≠공통수학2)"에
      한정**해 적용한다 — 선례 오적용으로 같은 과목을 둘로 쪼개지 않는다.
- [x] (b) **연장 — 기존 접두어 번호를 이어받는다.** 대상은 **§1 등록표에서 해당 과목에 실제로
      등록된 접두어 전부**이며, 각각 최대번호를 연장한다(예: 공통국어1은 `K-13~`).
      **이 문장에서 접두어를 재열거하지 않는다** — 정본은 §1이고 사본 열거는 반드시 어긋난다
      (260826 조건 C2 실증: 이전 문안 `T/W/E/F`는 실재하지 않는 `E`를 열거하고, 병합 대상인
      통합과학2의 7개 접두어 `GB GT MC ER CH BI UN`을 통째로 누락했다. CLAUDE.md 원칙 9-c-ii).
      같은 유형의 반복 관측을 한 유형ID에 누적한다(원칙 3 · 중요도 연도 반복 산정).
      분기(`K2-01~`)는 하지 않는다.
- [x] (c) **병기한다.** 2024 2학기 자료(2015 개정 세대)의 근거·이력 표기에는
      **"(2015 개정)"을 병기**하고, 성취기준 코드 칸은 현행(2022 개정) 대응이 불가능하면
      추측으로 채우지 않고 비고 처리한다(REV_GUIDE §2-b D blocked 준용). 유형 승격 판정에서
      2015 세대 근거는 **보조 근거**로 취급함을 명시한다.
- [x] **2024학년도(2015 개정 세대) 「수학」의 subject_code = `math1` 연장으로 확정**(260826,
      [OC 지시] 260826_03 P0-2 · 사용자 승인). 선례: `EX-math1-20241M`·`EX-math1-20241F`
      가 2015 개정 「수학」에 이미 math1을 배정해 왔다(HARVEST_LOG 등재분 — 소급 개명 금지 대상).
      §6 (a)의 "수학 분리 선례는 커리큘럼상 별개 과목 한정"에 따라, 같은 과목의 학기 연속인
      2015 개정 「수학」을 새로 쪼개지 않는다. 신규 부여: `EX-math1-20242M` · `EX-math1-20242F`.
      내용상 2015 개정 「수학(하)」가 현행 공통수학2 범위와 겹쳐도 **subject_code는 변경하지
      않으며**, 범위 대응은 (c) 병기 표기로 S2에서 처리한다.
