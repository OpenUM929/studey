## 2. 지문 성격(source register) — 실측 주제 계열

상산고 지문은 **각색된 원서 논픽션/저널** 계열이다. 실측된 지문 소재:
- **인문·사회 에세이**: 거짓말의 보편성(인간 본성), 행복·정체성, 공감(empathy)
- **과학·자연 저널리즘**: 도시 야생동물(Urban Wildlife Institute), 가뭄 대응 전략(케냐), 기술·공학
- **예술·문화**: Sophie Green 야생견 초상, 예술의 몰입 경험
- **응용·경영**: 쇼핑카트 도입 성공요인, 자원·비용 전략
- **심리·교육**: 학습 동기, 학생 정체성

→ 생성 시 **주제 계열을 위에서 고르고, 학술 nonfiction 문체**로 원문을 새로 쓴다. (특정 기사 복제 아님)

## 3. 어휘 수준 프로파일 (실측 상위 학술 어휘)

실제 지문에 반복 등장한 고급 어휘군:
`technology, environment, engineering, scientific, knowledge, potential, security, evidence, resources, alternative, population, treatment, individuals, emotional, citizens, particular, according, conditions, benefits`

- **등급**: 수능 필수어휘 + 고2~고3 심화 어휘. 극단적 GRE급 희귀어는 아님(교육과정 내).
- **관용·구동사**: 서답형(W-02)에 구동사·연어가 어형 변화와 함께 출제(speak up, stick to, managed to, checked on 등) → **동사구·연어 중심**, 난해 숙어보다 정확한 어형 변화가 포인트.

## 4. 구문 난이도 특징 (문장 수준)

- 평균 18.6단어의 **복문**: 관계절·분사구문·삽입구·대시(—) 삽입이 잦음.
- 서답형 **조건 영작(W-01)** 이 이 구문을 역으로 요구: **관계대명사·수동태 필수 포함**. → 학생이 복문 구조를 *생산*까지 해야 함(고난도 변별).

## 5. 생성 규격 (Generation Spec) — 지문 쓸 때 목표치

새 지문을 창작할 때 아래를 타깃으로 한다(자기검증 항목):

```
[ ] 길이: 120~170 단어(단일 지문). 복합 [A][B]는 각 90~130.
[ ] 평균 문장 길이: 16~20 단어. (너무 짧으면 하향)
[ ] 장단어(8자+) 비율: 16~20%.
[ ] Flesch-Kincaid: 10~12학년 목표. (계산해 확인)
[ ] 문장 구조: 관계절·분사구문·삽입 대시 최소 1~2회 포함.
[ ] 주제: 2절의 원서 논픽션 계열에서 선택.
[ ] 어휘: 수능 필수+고3 심화. 초고빈도어만으로 쓰지 말 것(FRE 45~55 유지).
[ ] 유형별 장치: 함축(은유 문장)·빈칸(논리 연결어)·순서(지시어) 심기.
```

- 난이도 Tier(난이도_루브릭 연계): 지문 자체 난이도는 대체로 **고정(수능 상위)**, 문항 난이도는 **묻는 방식(빈칸>일치, 함축>주제)** 과 선택지 매력도로 조절.

## 6. 정직한 한계
- Flesch류 지표는 **영어 원어민 기준 가독성**이라 한국 학습자 체감 난이도와 완전히 같지는 않음(문화·배경지식 변수). 그래도 **상대 비교·목표 설정용으론 신뢰**할 만함.
- 어휘 "등급"은 실측 빈도 기반 추정이며, 특정 어휘가 수능 필수인지 여부는 어휘집과 대조 시 더 정밀해짐.
- 2026 지문(스캔)은 표본만 반영. 전량 반영 시 수치 미세 갱신 가능(경향은 동일: 인문 에세이·과학 저널리즘·예술).
- 이력: 260714 신설. 근거: 2024·2025 전량(24,643단어) + 2026 표본 실측.
