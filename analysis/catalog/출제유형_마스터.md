# 출제 유형 마스터 — 단원 독립 범용 출제 문법 (정본)

> **목적**: 지금까지의 과목별 카탈로그는 "어느 단원에 무슨 내용이 나왔나"(내용 축)를 정리한 것이다.
> 이 문서는 그와 직교하는 **"어떤 방식으로 묻는가"(형식·인지 축)** 를 정리한다.
> 이 축은 **내용과 분리**되어 있으므로, **어느 단원·어느 과목에든 그대로 이식**할 수 있다.
>
> **핵심 원리**: 상산고의 모든 문항은 다음 6개 부품의 **조합**이다.
> ```
> 문항 = [A. 자극(자료)] × [B. 발문(요구)] × [C. 인지 조작] × [D. 선지/응답 구조] × [E. 함정 설계] × [F. 난이도 레버]
> ```
> 새 문제를 만들 때: **과목 카탈로그에서 '내용(유형 ID)'을 고르고, 이 문서에서 A~F 부품을 골라 결합**한다.
> 그러면 "이차함수든 조선 정치든 세포막이든" 동일한 출제 유형으로 준비·생산할 수 있다.

# A. 자극(자료) 유형 — 무엇을 제시하는가

| 코드 | 자극 | 주 사용 과목 | 이식 방법(임의 단원에 적용) |
|------|------|------------|------------------------|
| A1 | **줄글(설명·논설·사료·지문)** | 전 과목 | 개념 설명문/원 자료/원서 지문으로 제시. 밑줄·㉠㉡ 표시로 초점화 |
| A2 | **표(특징 유무 ○×, 조성비, 자료값)** | 과학·사회·수학 | 대상 A~C의 속성을 표로. 한 칸을 미지(ⓐ,㉠)로 비워 추론 유도 |
| A3 | **그래프(v-t, 기온·강수, 함수, 통계)** | 과학·사회·수학·영어 | 축·곡선 제시 → 값 읽기·경향·교점 판단 |
| A4 | **그림·모형(구조도·결합모형·세포·회로)** | 과학 | 구조를 그림으로. 부분 명칭을 ㉠~㉢로 물음 |
| A5 | **지도(세계·역사 지도, 분포도)** | 사회·한국사 | 위치 A~E에 대상 배치 → 위치 판별·매칭 |
| A6 | **대화·발표(교사–학생, 갑을병정무)** | 전 과목 | 여러 화자의 진술 → 옳은 화자/빈칸 추론 |
| A7 | **흐름도·순서도(분류 트리)** | 사회·과학 | 예/아니요 분기 → 분류 결과 판정 |
| A8 | **복합(A+B, 두 지문/두 자료)** | 영어·과학·사회 | (가)(나) 또는 [A][B] 병치 → 종합·대조 |
| A9 | **실물 사진·유물·문화유산** | 한국사·사회 | 유물/경관 사진 → 시대·지역·종교 식별 |

> **난이도는 자극의 '복잡도·간접성'에 비례** (F 참조). 같은 개념도 A1(직접 서술)→A2/A3(표·그래프 해석)→A8(복합)으로 갈수록 어려워진다.

# C. 인지 조작 유형 — 머릿속에서 무슨 일을 시키는가 (가장 중요한 축)

> **같은 단원 내용이라도 인지 조작을 바꾸면 완전히 다른 문항이 된다.** 이것이 "어느 단원에서든 유형을 준비"하는 열쇠.

## C1. 식별·분류 (Identify)
- 조작: 단서로 대상이 '무엇인지' 확정. "순서 없이 나타낸" A~C를 규정.
- 어느 단원에나: 원소/광물/소기관(과학), 기후/문화권(사회), 시대/국가/왕(한국사), 함수/도형(수학).
- 함정: 유사 대상 교차(비슷한 둘을 뒤바꿈).

## C2. 비교·대조 (Compare)
- 조작: A vs B의 공통점·차이점, 대소 관계.
- 어느 단원에나: 두 물체 운동량 대소, 두 사상가 입장, 두 제도(의정부서사제 vs 육조직계제), 두 지문 논지.
- 함정: 한쪽에만 참인 것을 공통으로, 대소 역전.

## C3. 적용·전이 (Apply)
- 조작: 개념·이론을 **새로운 사례/자료**에 적용.
- 어느 단원에나: 충격량 원리→새 안전장치 사례, 자기결정성 이론→새 상황 해석, 관점→새 현상, 곱셈공식→도형.
- 함정: 표면 유사하나 원리 불일치 사례.

## C4. 계산·정량 (Compute)
- 조작: 수치를 규칙에 따라 처리해 값 산출.
- 어느 단원에나: 물리 계산, 화학 양적관계, 수학 전 영역, 사회 통계·인구, 유전 염기 개수.
- 함정: 경계값(등호), 단위, 부호, 개수 세기.

## C5. 추론·인과 (Infer)
- 조작: 명시되지 않은 것을 논리로 채움(빈칸·함축·숨은 전제).
- 어느 단원에나: 영어 빈칸·함축, 사료 행간, 그래프 이면, 실험 결과 해석.
- 함정: 과대·과소 추론, 역인과.

## C6. 배열·구조화 (Sequence/Structure)
- 조작: 순서·위치·연표·삽입.
- 어느 단원에나: 영어 글 순서·문장 삽입, 한국사 연표·시기 사이 사건, 별 진화 순서, 우주 입자 생성 순서.
- 함정: 지시어·연결어 오독, 인접 구간 혼동.

## C7. 평가·판정 (Evaluate)
- 조작: 여러 진술/주체의 옳고 그름을 판정.
- 어느 단원에나: 옳은 학생/화자 고르기, 채점표(예/아니요 √) 정오, 실험 설계 타당성.
- 함정: 1칸만 틀려도 탈락(정밀), 방법론(변인) 오류.

## C8. 종합·생성 (Synthesize/Produce)
- 조작: 자료를 종합해 서술·영작·풀이 과정 작성.
- 어느 단원에나: 서술형 전 과목, 조건 영작, 풀이 과정.
- 함정: 채점 조건(용어·문법·완결성) 미충족.

# F. 난이도 레버 — 같은 유형을 쉽게/어렵게

1. **자극 간접성**: 직접 서술(A1) → 표·그래프 해석(A2·A3) → 복합 자료(A8).
2. **단계 수**: 1단계 계산 → 다단계(대입→연립→역산). (이 학생은 다단계에서 실점 — student 분석 참조)
3. **보기 조합 수(D2)**: ㄱㄴ 2개 → ㄱㄴㄷㄹ 4개.
4. **발문 방향**: B1(옳은 것) → B2(옳지 않은 것) → B5(2개 고르기).
5. **함정 밀도**: 오답 1개만 매력적 → 4개 모두 매력적.
6. **미지수·조건 결합**: 조건 1개 → 여러 조건 동시 만족(예: "적어도 하나는 3").
7. **배점**: 상산고는 난이도↑ 문항에 배점↑(2024 2.2~2.8 → 2025~2026 3.0~4.4). 배점이 난이도 신호.
