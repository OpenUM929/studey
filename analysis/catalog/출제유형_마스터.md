# 출제 유형 마스터 — 단원 독립 범용 출제 문법 (정본)

> **목적**: 지금까지의 과목별 카탈로그는 "어느 단원에 무슨 내용이 나왔나"(내용 축)를 정리한 것이다.
> 이 문서는 그와 직교하는 **"어떤 방식으로 묻는가"(형식·인지 축)** 를 정리한다.
> 이 축은 **내용과 분리**되어 있으므로, **어느 단원·어느 과목에든 그대로 이식**할 수 있다.
>
> **핵심 원리**: 상산고의 모든 문항은 다음 6개 부품의 **조합**이다.
> ```
> 문항 = [A. 자극(자료)] × [B. 발문(요구)] × [C. 인지 조작] × [D. 선지/응답 구조] × [E. 함정 설계] × [F. 난이도 레버]
> ```
> 새 문제를 만들 때: **과목 카탈로그에서 '내용(유형 ID)'을 고르고, 이 문서에서 A~F 부품을 골라 결합**한다.
> 그러면 "이차함수든 조선 정치든 세포막이든" 동일한 출제 유형으로 준비·생산할 수 있다.

# A. 자극(자료) 유형 — 무엇을 제시하는가

| 코드 | 자극 | 주 사용 과목 | 이식 방법(임의 단원에 적용) |
|------|------|------------|------------------------|
| A1 | **줄글(설명·논설·사료·지문)** | 전 과목 | 개념 설명문/원 자료/원서 지문으로 제시. 밑줄·㉠㉡ 표시로 초점화 |
| A2 | **표(특징 유무 ○×, 조성비, 자료값)** | 과학·사회·수학 | 대상 A~C의 속성을 표로. 한 칸을 미지(ⓐ,㉠)로 비워 추론 유도 |
| A3 | **그래프(v-t, 기온·강수, 함수, 통계)** | 과학·사회·수학·영어 | 축·곡선 제시 → 값 읽기·경향·교점 판단 |
| A4 | **그림·모형(구조도·결합모형·세포·회로)** | 과학 | 구조를 그림으로. 부분 명칭을 ㉠~㉢로 물음 |
| A5 | **지도(세계·역사 지도, 분포도)** | 사회·한국사 | 위치 A~E에 대상 배치 → 위치 판별·매칭 |
| A6 | **대화·발표(교사–학생, 갑을병정무)** | 전 과목 | 여러 화자의 진술 → 옳은 화자/빈칸 추론 |
| A7 | **흐름도·순서도(분류 트리)** | 사회·과학 | 예/아니요 분기 → 분류 결과 판정 |
| A8 | **복합(A+B, 두 지문/두 자료)** | 영어·과학·사회 | (가)(나) 또는 [A][B] 병치 → 종합·대조 |
| A9 | **실물 사진·유물·문화유산** | 한국사·사회 | 유물/경관 사진 → 시대·지역·종교 식별 |
| **A10** | **자극 부재 — 순수 문언 제시** (도형·상황을 글로만) | **수학(2학기 확인)** | 그림을 주지 않고 도형 조건만 서술 → **학생이 좌표축·변수를 스스로 세워야** 함 |

> **난이도는 자극의 '복잡도·간접성'에 비례** (F 참조). 같은 개념도 A1(직접 서술)→A2/A3(표·그래프 해석)→A8(복합)으로 갈수록 어려워진다.
>
> **⚠️ A10은 이 척도의 예외이자 상단이다** (260822 신설). 자극이 *적을수록* 쉬운 게 아니다.
> 근거: 공통수학2 부교재 시트 #1(평면좌표)은 **15문항 전체에 그림이 한 장도 없다.** 정삼각형·사각형
> 문항도 삽화 없이 텍스트뿐이라, **좌표를 어떻게 세우느냐가 곧 관문**이 된다(SM2-02·05·06).
> 시트 #3의 그림 8문항도 **전부 그림 없이 성립**한다(사분면·부등호 단서가 본문에 있음) — 그림은 보조일 뿐이다.
> → 수학 문항을 만들 때 **그림에 의존하지 않는 서술**이 기본값이고, A10은 난이도를 올리는 레버다.

# B. 발문(요구) 유형 — 어떻게 묻는가

| 코드 | 발문 | 특징 | 이식 |
|------|------|------|------|
| B1 | **옳은 것은?** | 4오답 1정답 | 참 1 + 미세 왜곡 4 |
| B2 | **옳지 않은 것은?** | 4참 1오답 | 참 4 + 결정적 오류 1 (더 어려움 — 4개가 참임을 다 확인해야 안심) |
| B3 | **옳은 것만을 <보기>에서 있는 대로** | ㄱㄴㄷ(ㄹ) 합답 | 상산고 최빈. C·D·E 조합의 핵심 그릇 |
| B4 | **가장 적절한 것은?** | 최선 택1 | 정도·범위 미묘한 매력 오답 |
| B5 | **옳은 것 2가지 / 옳지 않은 것 2가지** | 복수 정답 | 사회·한국사. 부분 오답 방지 |
| B6 | **빈칸(㉠/가/A)에 들어갈 것** | 추론 | 앞뒤 논리·인과로 채움 |
| B7 | **밑줄 친 ~이 의미하는 바** | 함축·재진술 | 영어·국어. 표면 직역 오답 |
| B8 | **순서 배열 / 위치 삽입** | 구조 | 지시어·연결어 단서 |
| B9 | **무엇인지 판별(순서 없이 제시)** | 식별 | A~C가 각각 무엇인지 단서로 확정 |
| B10 | **점수·개수·값 구하기** | 정량 | 채점표 점수, 정수 개수, 계산값 |
| B11 | **서술/영작(조건 명시)** | 생성 | 용어 정확·문법 필수·완결 문장 조건 |
| **B12** | **"~을 모두 구하시오"** (서답형 복수 정답) | 누락 감점 | B5의 서답형 판. ± 두 해·양방향 2해가 나오는 구조에서 **하나만 쓰면 감점**. 수학 2학기 확인(SM2-10·12) |
| **B13** | **정수 환산 요구** ("a²+b²의 값", "k²", "16S²", "ab") | 채점 장치 | 답이 무리수·분수로 나오는 문항에서 **정수로 떨어지는 조합값**을 묻는다 |

> **B13은 새 발견이 아니라 기존 규칙의 구체화다.** [난이도_루브릭.md](난이도_루브릭.md) 5절 자기검증 1번이
> 이미 *"정답이 유일하고 **깔끔한 값**(정수·기약분수 등)인지 확인. 상산고 답은 대개 깔끔함"* 이라고 규정했다.
> B13은 그 "깔끔함"이 **어떤 장치로 만들어지는지**를 발문 축에 코드로 고정한 것이다.
>
> 1학기 `a²+b²+c²=26`(SM-02),
> `abc=128`(SM-03), `a+b=4`(SM-05) ↔ 2학기 `16S²=243`(SM2-06), `k²`(SM2-22), `a²+b²`(SM2-24),
> `m+n√5`(SM2-16), `ab=−8`(SM2-33). 시트 #3에서만 8문항이 이 장치를 쓴다.
> **효과 두 가지**: ① 채점이 단답으로 떨어짐 ② **중간 계산을 틀리면 정수가 안 나와 학생이 스스로 검산**하게 됨.
> 새 문항도 이 장치를 기본으로 쓴다. 단 **계수가 분모를 정확히 상쇄하도록 설계**해야 한다(SM2-06 `a+4b`처럼).

# C. 인지 조작 유형 — 머릿속에서 무슨 일을 시키는가 (가장 중요한 축)

> **같은 단원 내용이라도 인지 조작을 바꾸면 완전히 다른 문항이 된다.** 이것이 "어느 단원에서든 유형을 준비"하는 열쇠.

## C1. 식별·분류 (Identify)
- 조작: 단서로 대상이 '무엇인지' 확정. "순서 없이 나타낸" A~C를 규정.
- 어느 단원에나: 원소/광물/소기관(과학), 기후/문화권(사회), 시대/국가/왕(한국사), 함수/도형(수학).
- 함정: 유사 대상 교차(비슷한 둘을 뒤바꿈).

## C2. 비교·대조 (Compare)
- 조작: A vs B의 공통점·차이점, 대소 관계.
- 어느 단원에나: 두 물체 운동량 대소, 두 사상가 입장, 두 제도(의정부서사제 vs 육조직계제), 두 지문 논지.
- 함정: 한쪽에만 참인 것을 공통으로, 대소 역전.

## C3. 적용·전이 (Apply)
- 조작: 개념·이론을 **새로운 사례/자료**에 적용.
- 어느 단원에나: 충격량 원리→새 안전장치 사례, 자기결정성 이론→새 상황 해석, 관점→새 현상, 곱셈공식→도형.
- 함정: 표면 유사하나 원리 불일치 사례.

## C4. 계산·정량 (Compute)
- 조작: 수치를 규칙에 따라 처리해 값 산출.
- 어느 단원에나: 물리 계산, 화학 양적관계, 수학 전 영역, 사회 통계·인구, 유전 염기 개수.
- 함정: 경계값(등호), 단위, 부호, 개수 세기.

## C5. 추론·인과 (Infer)
- 조작: 명시되지 않은 것을 논리로 채움(빈칸·함축·숨은 전제).
- 어느 단원에나: 영어 빈칸·함축, 사료 행간, 그래프 이면, 실험 결과 해석.
- 함정: 과대·과소 추론, 역인과.

## C6. 배열·구조화 (Sequence/Structure)
- 조작: 순서·위치·연표·삽입.
- 어느 단원에나: 영어 글 순서·문장 삽입, 한국사 연표·시기 사이 사건, 별 진화 순서, 우주 입자 생성 순서.
- 함정: 지시어·연결어 오독, 인접 구간 혼동.

## C7. 평가·판정 (Evaluate)
- 조작: 여러 진술/주체의 옳고 그름을 판정.
- 어느 단원에나: 옳은 학생/화자 고르기, 채점표(예/아니요 √) 정오, 실험 설계 타당성.
- 함정: 1칸만 틀려도 탈락(정밀), 방법론(변인) 오류.

## C8. 종합·생성 (Synthesize/Produce)
- 조작: 자료를 종합해 서술·영작·풀이 과정 작성.
- 어느 단원에나: 서술형 전 과목, 조건 영작, 풀이 과정.
- 함정: 채점 조건(용어·문법·완결성) 미충족.

## C9. 역산·역추적 (Inverse) ⭐ 260822 신설
- 조작: **결과를 주고 원인을 되찾게** 한다. 정방향 공식을 아는 것만으로는 부족하고 식을 뒤집어야 한다.
- 어느 단원에나: 상(像)에서 원상 찾기·이동량 역추적(수학 SM2-31·32), 접점 사이 거리에서 반지름 역산
  (SM2-24), 넓이 조건에서 계수 역산(SM2-13·27), DNA 조성표 역산·전자배치 상댓값 역산(통합과학),
  결과 사료에서 시기 추정(한국사).
- 함정: 정방향으로 풀려다 미지수 폭증 / **이동·대칭을 방정식으로 쓸 때 부호가 반대**(SM2-31) / 역산 해가 2개.
- 비고: **개념 자체는 이미 있었다** — 이 문서 F축 2번(*"1단계 계산 → 다단계(대입→연립→**역산**)"*)과
  [난이도_루브릭.md](난이도_루브릭.md) 4절(통합과학 *"조성표 역산"*, 수학 *"계수합=대입법"*).
  260822에 한 일은 흩어져 있던 이 개념에 **인지 축 코드를 부여해 F축·루브릭과 연결**한 것뿐이다.

## C10. 경우 분기 · 해의 개수 통제 (Branch) ⭐ 260822 신설
- 조작: 조건이 **몇 개의 해를 허용하는지 스스로 판정**하고, 필요한 만큼만 남긴다.
  출제자는 **발문의 단어 하나로 해의 개수를 조절**한다.
- 대표 실측(공통수학2):
  - `"직선 AB 위의 점"` → **양방향 2해** (그래서 최대 M·최소 m을 물음) / `"연장선 위 + a>0"` → **1해** (SM2-04)
  - 양축에 접하는 원 → 중심 (a, a)와 (a, −a) **두 계열** — 한쪽만 보면 오답 (SM2-16)
  - 각의 이등분선 → **± 두 직선** → "모두" 요구(B12)인지 배제 조건("원점을 지나지 않는")인지에 따라 정답 개수가 갈림 (SM2-12)
  - 공통접선 4개 중 사분면·선분 조건으로 선별 (SM2-24)
- 어느 단원에나: 절댓값·제곱근 방정식의 부호 분기(수학 1학기 SM-11·13), 실험 조건 분기(과학),
  사료 해석의 복수 가능성(한국사).
- 함정: 한쪽 계열 누락(최다 오답) / 반대로 배제 조건을 무시하고 전부 답함 / 분기 후 **교집합**을 안 취함.

# D. 선지/응답 구조 — 답을 어떻게 받는가

| 코드 | 구조 | 비고 |
|------|------|------|
| D1 | 5지선다 단일 정답(①~⑤) | 기본 |
| D2 | **ㄱㄴㄷ(ㄹ) 합답 조합**(①ㄱ ②ㄴ ③ㄱㄴ …) | 상산고 주력. 보기 개수·조합으로 난이도 조절 |
| D3 | 짝짓기(관점–질문, 지역–특징, (가)(나)–A~D) | 표/지도 매칭 |
| D4 | 체크표(갑~무 × 항목 √) → 옳게 표시한 주체 | 전부 맞아야 정답 |
| D5 | 단답(용어·명칭·값·발음) | 채점 조건 명시 |
| D6 | 서술/영작(부분 배점) | 채점 기준 재현 |

> **⚠️ 수학은 D1·D2를 쓰지 않는다.** 이미 [수학.md](수학.md) 헤더에
> *"단답형/서술형 중심(2026 확인). 전 문항 풀이 과정·답 요구형(수능 5지선다 아님)"* 으로 규정돼 있다.
> 260822에 2학기 부교재 93문항으로 **재확인**했을 뿐이다(선택형 0건, 서답형 100%). 수학 문항은 **D5(단답) + D6(서술)** 로만 만든다.
> 부교재에 "~은?" 형태의 의문형 종결이 3건 섞여 있으나, 이는 객관식 원출처에서 선지만 떼어낸 흔적이므로
> **재현하지 않고 "~을 구하시오"로 통일**한다.

# E. 함정(오답) 설계 유형 — 어떻게 틀리게 만드는가

> 좋은 변형 문제 = 좋은 함정. 아래 패턴을 오답지에 심는다(과목 무관 공통).

| 코드 | 함정 | 예 |
|------|------|-----|

# F. 난이도 레버 — 같은 유형을 쉽게/어렵게

1. **자극 간접성**: 직접 서술(A1) → 표·그래프 해석(A2·A3) → 복합 자료(A8).
2. **단계 수**: 1단계 계산 → 다단계(대입→연립→역산). (이 학생은 다단계에서 실점 — student 분석 참조)
3. **보기 조합 수(D2)**: ㄱㄴ 2개 → ㄱㄴㄷㄹ 4개.
4. **발문 방향**: B1(옳은 것) → B2(옳지 않은 것) → B5(2개 고르기).
5. **함정 밀도**: 오답 1개만 매력적 → 4개 모두 매력적.
6. **미지수·조건 결합**: 조건 1개 → 여러 조건 동시 만족(예: "적어도 하나는 3").
7. **배점**: 상산고는 난이도↑ 문항에 배점↑(2024 2.2~2.8 → 2025~2026 3.0~4.4). 배점이 난이도 신호.
