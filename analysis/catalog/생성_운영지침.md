# 생성 운영 지침 — 문제 생성 실전 파이프라인 (정본)

> 260714 신설. 대화에서 합의된 운영 규칙을 문서로 고정(대화 소실 방지).
> "무엇을·어떻게·어느 수준으로" 3축을 **어떤 순서·어떤 모델·어떤 자료·어떤 검증**으로 돌리는지 규정.

## 1. 생성 파이프라인 (4단계 — 항상 이 순서)
1. **내용**: 과목 카탈로그에서 유형 ID 선택(중요도 ★★★ 우선) + 목표 소주제(진도 범위 내).
2. **형식·인지**: [출제유형_마스터.md](출제유형_마스터.md)에서 A(자극)·B(발문)·C(인지)·D(선지)·E(함정) 조합.
3. **난이도**: [난이도_루브릭.md](난이도_루브릭.md)로 목표 배점(Tier)→DF 특징 레시피 적용.
4. **자기검증**(필수):
   - 수학·과학: **solve-back**(직접 풀어 정답 유일·단계 수·모순 확인).
   - 영어: 지문 **FK 계산**(목표 10~12) + 정답 유일성.
   - 국어·사회·한국사: **정답 유일성 체크**(오답마다 '왜 틀림' 한 줄).
5. **출력 형식**: 문제 + 정답 + 해설 + **유형ID + Tier + 활성 DF코드**. 미확정 용어는 "⚠️ 용어 검수".
6. 산출물 저장: `output/YYMMDD/`.

## 1-A. 출력 서식 규칙 (필수 — 렌더링 깨짐 방지)
> 마크다운은 **단일 줄바꿈을 무시**해 선지가 한 줄로 붙는다. 반드시 아래를 지킬 것.
- **선지 ①~⑤는 각각 독립된 줄**에 출력하고, **각 줄 끝에 하드 브레이크(공백 2칸)** 를 붙인다. (또는 각 선지 사이 빈 줄)
- **`<보기>` ㄱ·ㄴ·ㄷ·ㄹ**도 각각 독립된 줄 + 하드 브레이크.
- **순서·짝짓기 선지**(①(A)-(C)-(B) …)도 한 줄에 몰지 말고 **각 선지 줄 분리**.
- 지문 / 발문 / `<보기>` / 선지 / 정답 블록은 **빈 줄로 시각 분리**. 지문은 한 문단으로.
- 요약문·빈칸의 (A)/(B) 표는 정렬 유지. 정답·해설 표는 표 형식 그대로.
- 생성 직후 **"선지가 줄 단위로 분리되어 보이는가"** 를 서식 자기검증 항목으로 확인(파이프라인 4단계에 포함).
- **한 줄 선지 몰아쓰기 절대 금지**: ①~⑤를 한 줄로 몰아쓰면(`①… ②… ③…`) 뷰어·변환 파서가 ①만 인식하고 ②③④⑤가 유실되어 정답·보기 자체가 깨진다. 반드시 줄 단위 분리(하드 브레이크 또는 빈 줄).
- **지문 내 numbering 은 회피됨**: 파서는 "줄 **시작**이 원숫자"일 때만 선지로 판별하므로, 지문 중간에 들어가는 넘버링(예: `The three causes are ① heat, ② moisture, ③ wind.`)은 선지로 오인되지 않고 지문으로 보존된다. 즉 선지 줄바꿈은 지키되 지문 안 numbering 은 건드리지 않아도 된다. (단, 지문 줄이 원숫자로 **시작**하면 선지로 오인되므로, 지문은 원숫자로 시작하지 않게 작성.)

## 2. 모델 선택 (하이브리드 권장)
| 작업 | 권장 모델 | 이유 |
|------|----------|------|
| 유형·형식 준수, 언어 과목 T1~T3, 영어 지문 창작 | **Sonnet** | FK·형식은 스크립트/템플릿 검증 → 비용 효율. 대량(≈85%) 담당 |
| 수학·과학 **전 문항 solve-back 검증**, **T4 킬러**, 최종 QA 패스 | **Opus / 프런티어** | 정답 보증·통찰이 필요한 꼬리(≈15%) |
> 핵심: 지침이 바닥을 올려 Sonnet도 대부분 가능. **"검증 루틴 준수"가 모델 체급보다 실전 품질을 더 좌우.**

## 3. 자료 조달 & 저작권 (개인 학습용 기준)
| 자료 | 방법 |
|------|------|
| 사료(한국사)·사상가 원전·**저작권 만료 근대 정전 문학** | **실제 원문 사용** |
| 현대(생존 작가) 문학·EBS/원서 영어 지문 | **사용자 원문 제공** → 그 위에 출제 / 없으면 동급 창작 |
| 신문·통계·매체 자료 | 동급 창작 |
> 금지: 기억으로 현대 저작물을 **부정확하게 복원**(할루시네이션). 정확도 위해 제공받거나 창작.

## 4. 과목별 준비 입력 요건 (2학기 등)
- **필수**: 대주제 + **소주제(=진도 범위)** + 난이도 분포.
- **선택**: 출판사(용어·표기 검수용) / 언어과목 지문·작품 원문.
- **영어 교과서 연계율**: 시험지만으론 측정 불가(교과서 지문의 수능형 재가공 때문). **시험범위 공지 or 교과서 채택본**이 있어야 "교과서 vs 외부" 비율 확정. 없으면 외부·수능형 위주로 창작(추정 교과서 30%/외부 70% ±).
- **성취기준 코드**: NCIC 공식본으로 확인(기억 금지).

## 5. 난이도 분포 기본값(100문제)
T1 하 25 · T2 중 35 · T3 상 30 · T4 킬러 10 (자사고는 T3·T4 상향 가능). 근거: 난이도_루브릭 6절.

## 6. 신뢰도 지도 (과목·영역별 — 어디에 검수를 더 쓸지)
- **최상(검수 최소)**: 수학, 통합과학, **국어 문법**(규칙·자기검증).
- **상(창작+근거)**: 비문학 독해(영/국), 고전·근대정전 문학, 통합사회·한국사(자료 근거 설계).
- **검수 강화**: 현대(생존작가)문학 감상, 화법·작문·매체 → 고신뢰 설계 규칙(국어.md) 적용 후에도 최종 확인.
