# 자료 매핑 확장 및 학생 오답 표준 검토

<document>

- DATA_STANDARD §1.3: 코퍼스 폴더명은 코퍼스ID와 일치하며 소급 개명하지 않는다.
- §5.7: `grade`는 자료 등급이며 학생 학년이 아니다. 자료 회차 `exam_code`와 제목은 있으나 자료 역할·적용 학년·복수 평가 범위 연결 규격은 없다.
- §5.8: 생성 세트에 `student`, `term`, `unit`, `scope_confirmed`, `intended_use`가 있다.

- AUTHORING_GUIDE §1-B 및 item-writer: 비수치 변형축 최소2개, 최근접 선행 문제와 풀이 구조 대조, 신규성 원장 필수.

## 1. 저장 구조: 이동보다 매핑 확장

현재 ID 기반 물리 저장과 메타데이터 참조 방식은 확장 가능하다. 따라서 **학년/학기/중간·기말 물리 폴더 신설안은 채택하지 않는 방안**을 제안한다. 기존 파일은 이동·복제하지 않고 해당 기준으로 조회 가능한 매핑을 추가한다. 사용자의 자료 분류 요구 자체를 폐기하는 것은 아니다.

단, 현 스키마가 이미 요구를 충족하는 것은 아니다. 자료의 출처 회차와 활용할 평가 범위는 다르며 한 자료를 여러 범위에 연결할 수 있어야 한다. 수행평가를 중간·기말과 같은 단일 enum에 억지로 넣으면 '중간 범위의 수행평가' 관계가 사라진다. 기존 SUP ID를 PA로 소급 개명하지 않는다.

## 2. 학생 표준 실측: 구조는 일부 정상, 사용 가능성은 미충족

읽기 전용 명령: `python -X utf8 analysis/rev/260909_01_material_student_probe.py`.

| 파일 | 데이터 행 | BOM | 열수 불일치 | 비ASCII 셀 | sha256 앞16자 |
|---|---:|---|---:|---:|---|
| student/S01/ATTEMPT_LOG.tsv | 0 | 있음 | 0 | 0 | c130c71adccdb558 |
| student/S01/MASTERY.tsv | 131 | 있음 | 0 | 201 | d637117febfac18d |
| student/S01/WEAK_LEDGER.tsv | 1 | 있음 | 0 | 3 | ffae9938e32910ed |

ATTEMPT_LOG 헤더12열은 §5.1과 일치하나 응시 기록은 없다. `python -X utf8 tools/build_mastery.py --check`는 `[FAIL] MASTERY.tsv differs from regeneration`을 반환했다. 재생성 불일치의 세부 원인은 아직 조사하지 않았으며 자동 덮어쓰지 않았다. ASCII 위반은 표준 예시에도 존재하므로 학생 파일만 일괄 영문화하는 것으로 해결하면 안 된다.

S01 profile은 skeleton이며 목표 등급은 TBD, created는 ISO가 아닌260825이다. 기존 수학 분석에는 경계 처리(E5) 취약 **후보**가 있으나 판독 불확실성과 공식 정답 부재가 명시됐다. 이를 '자주 틀림'으로 확정할 반복 응시 근거는 없다. 이전40·25제의 실제 채점 데이터도 현재 ATTEMPT_LOG에서는 확인되지 않는다. 유형ID와 오류코드를 연결할 구조는 있으나 '학생 약점 검증 완료'라고 주장할 수 없다.

초기 인라인 진단은 괄호 SyntaxError로 실패했다. 이후 별도 읽기 전용 진단 파일로 재실행했으며 위 수치는 그 성공 출력이다. textpatch 자체시험 seeded=10 undetected=0; 시험용 혼합 줄바꿈 FAIL/WARN은 의도된 검출 출력이다. 학생 원장·정본·제품은 수정하지 않았다.

## 반영용 지침 초안 — 아직 운영 정본 아님

- [ ] **자료 역할**: 개념·교과서 설명은 참고 자료, 평가·연습 문항은 문제 자료로 구분한다. 혼합 파일은 페이지/절/문항 범위를 나눠 역할을 부여하며 동일 바이트 사본을 양쪽에 만들지 않는다. 출처의 자료 등급은 별도 축으로 보존한다.
- [ ] **범위 매핑**: 기존 자료ID에 학년도·학생 학년·학기·중간/기말 대상·평가 성격·과목·포함 페이지/문항ID·사용자 확인 근거와 날짜를 연결한다. 수행평가 차수 미상은 임의 P01을 발급하지 않는다. 여러 회차 적용은 별도 관계 행으로 표현한다. 필드명·enum·저장 형식은 DATA_STANDARD에 선행 등록한 뒤 사용한다.
- [ ] **범위 확정**: 문제 자료로 확인한 범위에 사용자 제공 정보를 함께 기록해 확정한다. 사용자 지정 연습 범위 확정과 학교의 공식 시험범위 확정을 구별한다. 자료 충돌·정보 누락·현행 교육과정 충돌은 해당 부분을 보류하고 사람에게 묻는다. 참고 자료만으로 범위를 확대하지 않는다.
- [ ] **생성**: 승인된 유형과 확정 범위에서 주유형·보조유형을 결합한다. 참고 자료는 개념·정의·표현 검증에 활용하고 문항을 베끼지 않는다. 참고 자료가 없어도 직접 생성하되 교육과정·승인 카탈로그·정답 검증은 생략하지 않는다. 원본은 조정자의 비교 검수 입력, 작성자는 승인 카탈로그와 조정자가 동결한 유사성 제약을 소비한다.
- [ ] **복합성·신규성**: 문항에 두 유형 태그를 붙이는 것으로 끝내지 않는다. 한 유형에서 얻은 조건이 다른 유형의 추론에 실제로 쓰여야 한다. 비수치2축 변경뿐 아니라 핵심 풀이 경로 차이를 설명하고 원본·기존40/25/32/32u·신규 두 세트 상호 간 대조한다. 승인 유형 결합은 가능하나 새 정본 유형ID 발급은 기존 외부 분류 절차를 따른다.
- [ ] **학생 맞춤**: 모든 학생 대상 생성에서 profile·ATTEMPT_LOG·재생성 검증된MASTERY·WEAK_LEDGER·관련 분석을 읽는다. 확정 취약 유형 중 범위 내 항목을 세트 설계에 필수 배정하고 출제 문항→취약 축→근거 응시를 추적한다. 범위 밖 취약 유형은 개념을 무단 이식하지 않는다. 최고난도 두 세트에서도 이 조건을 각각 적용한다. 근거가 없으면 약점을 발명하지 않는다.
- [ ] **표준 수선**: ASCII 규칙과 예시·생성기 간 충돌을 별도 소유자 변경으로 수선한다. 기존 append-only 행은 보존하고 교사 판단 없는 약점 상태 변경·가짜 시도 이력 생성은 금지한다. MASTERY는 원인 확인 후 도구로 재생성하며 손편집하지 않는다.

## 동반 변경 및 검증 순서

1. DATA_STANDARD(역할/관계/확정근거 스키마), DOC_LOCATION·corpus/_README(물리 저장 유지), CLAUDE(범위·생성 규칙), AUTHORING_GUIDE·item-writer(학생 입력·복합성), type-extractor(역할 사실 기록), FORECAST_GUIDE(사용자 범위와 예측 구별), analysis/student/_README(학생 입력 게이트)를 소유자 단계에서 함께 점검한다. 각 정본의 동반 목록도 따른다. 이 검토 패스로 직접 고치지 않는다.
2. 매핑 소비 도구·뷰어와 학생 원장 소비 도구의 현재 연결을 조사한 뒤, 회귀 테스트를 먼저 작성한다. 혼합 파일, 복수 평가 연결, grade 충돌 방지, 미확정 범위, 빈 학생 이력, stale MASTERY, 범위 밖 약점, 두 세트ID 충돌을 실패/성공 사례로 포함한다. 새 외부 의존성은 추가하지 않는다.
3. 자료 관계 등록 후 원본 문항ID를 매번 다시 추출하여 등록된 포함ID와 집합 비교한다. 중복/누락/추가/출처 불일치를 출력한다. 등록137개 같은 단순 합계로 전수 검증을 대신하지 않는다.
4. 선행64문항 검수·교체 완료 후 신규50문항을 작성한다. 정답/중간식 검산, 난도 및 신규성 검수, 외부 필수 검증 뒤 기존 output 홈의 문제·답·index·보고서를 함께 갱신한다.
