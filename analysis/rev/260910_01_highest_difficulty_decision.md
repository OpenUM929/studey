# 최고 난이도 재정의 — 사용자 요구 반영안

<document>
현행 루브릭 §1은 상대배점 r의 적용을 선택형에 한정하며, 수학 서답형에는 분모가 정의되지 않는다고 명시한다. §3 T4는 다단계·조건 결합·통찰·융합을 요구하고, §5는 짧은 풀이가 발견되면 재설계하도록 한다. REV_GUIDE §5의 two-key 대상이므로 이 제안서는 정본을 대체하거나 판정을 발급하지 않는다.
</document>

<context>
목적은 상산고 1학년 2학기 중간고사 대비다. 수학의 사용자 지정 자료 범위는 수행평가(스무년 고1-2)와 2024·2025년 2학기 중간고사이며, 정보는 사용자가 확인한 교과서·개념 문서·퀴즈·2025년 중간고사를 사용한다. 자료 기반의 요청 범위와 올해 학교 공지로 확인된 실제 시험 범위는 구분한다. 기존 최고 난이도가 쉽다는 학생 반응은 사용자 보고이며, 문항별 정답률·소요시간·무힌트 풀이 기록은 아직 이 요청에 주어지지 않았다.
</context>

<findings>

## 1. 즉시 반영할 출제 방향과 한계

- 기존에 최고 난이도로 부른 묶음은 이 학생에게 **상급 연습의 비교 기준**으로 취급한다. 새로운 최고 난이도의 달성 증거로 재사용하지 않는다.
- 다만 모든 기존 문항의 정식 Tier를 일괄 강등했다고 기록하지 않는다. 쉬웠던 원인이 낮은 인지 요구인지, 선행 노출과 숙련인지 문항별 재평가로 구별해야 한다.
- 수학 서답형에 선택형 상대배점 r을 적용하거나, 높은 배점을 붙여 최고 난이도로 인증하지 않는다.
- 신규 25제 두 세트는 **중간고사 범위 최상위 심화 훈련지**를 목표로 한다. 실제 중간고사의 일반적인 난이도 분포를 재현한 모의고사라고 부르지 않는다.

## 2. 제안하는 구별

| 구분 | 상급 | 새 최고 난이도 목표 |
|---|---|---|
| 첫 접근 | 익힌 유형에서 사용할 도구가 비교적 명확 | 어떤 표현·보조 관계를 도입해야 할지 스스로 선택 |
| 결합 방식 | 익숙한 두 절차를 차례로 실행 | 한 관계에서 얻은 제약이 다른 관계의 해석·해 후보를 바꿈 |
| 핵심 추론 | 한 번의 발상 뒤 정형 계산 | 서로 의존하는 핵심 판단을 연결해야 함 |
| 마무리 | 구한 값을 대입해 답 | 존재·경계·경우의 완전성 또는 등호 달성 가능성까지 확정 |
| 기존 학습 효과 | 기존 풀이 틀을 기억하면 곧바로 진입 | 기존 틀만 대입해서는 해결되지 않는 구조적 차이 |

**제안 정의:** 범위 안의 익숙한 개념만 쓰되, 풀이 방법의 선택 → 조건의 상호 제약 해석 → 후보 또는 경계의 완전한 검증이 연결되고, 기존 세트의 풀이 틀을 그대로 이식해서는 해결되지 않는 문제.

이 정의는 조건 개수·유형 ID 개수·풀이 줄 수를 세는 새로운 점수제가 아니다. 두 개념만으로도 깊은 문제가 가능하며 세 개념을 단순 나열한 문제는 탈락 후보다. ‘모든 문항에 반드시 역산’처럼 하나의 새 템플릿으로 획일화하지 않는다.

## 3. 최고 난이도로 인정하지 않을 설계

1. 계수·좌표·이름만 변경하거나 기존 풀이의 순서만 바꾼 것.
2. 같은 공식을 반복하게 하거나 수를 지저분하게 해 시간이 오래 걸리는 것.
3. 서로 독립인 쉬운 소문항을 묶어 복합 유형이라고 부르는 것.
4. 외분·범위 밖 정리·낯선 문법 등 범위 초과를 난이도로 이용하는 것.
5. 잉여 조건·불명확한 문장·과도한 독해량을 숨은 조건이라고 부르는 것.
6. 작성자의 긴 해설만 근거로 어렵다고 판정하는 것. 더 짧은 유효 풀이를 먼저 찾는다.

## 4. 문항별 재평가에 필요한 증거

기존 원본·25/40/32/32u와 신규 A/B를 비교할 때 문항마다 아래 내용을 남긴다. 이것은 감사에 제출할 증거 양식 제안이지 자기 승인 게이트가 아니다.

- 정확한 문항 식별자·문제 해시·허용 범위 근거.
- 가장 가까운 기존 문항과 `주어진 것 / 요구 행동 / 풀이 골격` 대조.
- 기존 novelty schema의 비수치 변형 축 두 개 및 실제 본문의 대응 근거.
- 핵심 판단의 의존 관계: 앞 판단을 제거하면 뒤 판단이 왜 성립하지 않는가.
- 가장 짧게 찾은 유효 풀이와 익숙한 유형으로 환원되는 우회 풀이 탐색 결과.
- 해의 유일성 또는 모든 해의 완전성, 조건 충분성·필요성, 경계·등호 확인.
- 작성자 자기검산과 별도 컨텍스트 맹목 풀이를 분리한 결과.
- 난이도는 `목표`와 `독립 검토 결과`를 구분. 실제 학생 수행 기록이 없으면 실증 최고 난이도라고 쓰지 않는다.

학생 피드백은 가능하면 무힌트 정오·시간·힌트 사용·기존 풀이 인지 여부로 수집한다. 단일 학생 기록은 해당 학생 맞춤 보정이며 모집단 정답률로 일반화하지 않는다. 기록이 없다고 출제 자체를 멈추지는 않되 개인화 달성을 주장하지 않는다.

## 5. 수학 출제 설계에 적용할 방향

아래는 완성 문항이나 신규 유형 등록이 아닌 설계 후보다. 각 후보의 범위·카탈로그 근거와 기존 문항 대비 신규성은 실제 문항 작성 후 별도 확인한다.

| 설계 방향 | 상급 수준에서 멈추는 방식 | 최고 난이도 목표를 위한 구조 변화 |
|---|---|---|
| 거리 조건과 원·직선 | 좌표를 연립해 거리 계산 | 거리 조건이 만드는 자취를 찾아 다른 제약과의 공존 가능성까지 역으로 결정 |
| 원과 직선의 교점 | 판별식에 바로 대입 | 주어진 기하량에서 후보 배치를 복원하고 누락·중복되는 경계를 선별 |
| 도형의 이동 | 주어진 변환을 차례로 계산 | 허용된 이동의 결과 조건으로 원래 배치를 복원하고 가능한 경우의 완전성을 설명 |
| 경로 최적화 | 대칭 한 번으로 최단거리 | 최적 경로의 후보가 실제 허용 구간에 있는지 검증하고 불가능한 경우 경계 후보와 비교 |
| 매개변수 기하 | 각 조건을 따로 계산 | 한 조건의 경계가 다른 조건의 성립 구간을 바꾸도록 결합하고 최종 허용 집합을 결정 |

정보에도 원칙은 동일하다. 긴 코드 추적 대신 관측 결과에서 조건 복원, 반례를 통한 오류 진단, 수정의 충분성 검증 등 사고의 전환을 설계한다. 교과서에서 확인하지 않은 알고리즘 이름·문법은 어렵게 보이게 하려는 목적으로 추가하지 않는다.
</findings>
