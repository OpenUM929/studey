**F-SC-1 (검증됨, INT-2 확정) — 서술형 배점 인덱스 22점 vs 본문 40점 불일치를 독립 재현**

`[n점]` 표식을 직접 대조·합산했다(재현: python 합산 `[10,10,2,2,6,10]`→40,
`[3,3,4,7,3,2]`→22). **type_analysis_SC.md L23-46의 재현표가 정확하다**. 또한 단순 순서 어긋남이
아니라 값 자체가 인덱스·본문 두 집합 간 교집합이 없다(인덱스에만 있는 값 {3,4,7}, 본문에만
있는 값 {10,6}) — "서술형1·2 소문항 배점을 서술형1~5 총점으로 오귀속"이라는 문서의 설명(L38-40)이

**F-SC-2 (검증됨) — 본문 채택값이 하위 산출물(type_analysis·catalog_update) 전체에 일관 적용됨**
`type_analysis_SC.md:100`의 "선택형 60.0 + 서술형 40 = 100.0"을 독립 재계산했다
(선택형 23문항 인쇄배점 합 = 60.0, 재현: python 합산 23개 값 → 60.0). `catalog_update_SC.md:109`
(서술형2 "10점(소문항 7+3)")·`:145`(서술형6 "10점")도 본문 채택값과 일치한다. **인덱스값(22)이

**F-SC-3 (검증됨) — DQ-SC-1(신규 ID 정책 공백) 진단의 정확성**
CODE_REGISTRY.md를 직접 열람해 §1(접두어 등록표, GB/GT/MC/ER/CH/BI/UN 7종만 등록, 통합과학2 신규
영역 접두어 없음)과 §6 260826 결정 블록 (a)(b)(병합+연장, "커리큘럼상 같은 과목의 학기 연속"인
5과목에 한정 적용, science 포함)를 대조했다. 통합과학2는 §6(b)의 "연장" 대상(과학은 병합 5과목
목록에 포함)이지만, **연장 대상은 "기존에 등록된 접두어"뿐**이고 통합과학2가 다루는 것은
"기존 7개 영역과 무관한 신규 영역(원자핵·산화환원 정량·진화·생태 등은 기존 GB/GT/MC/ER/CH/BI/UN에
느슨하게 걸치지만 28/29문항이 새 조합)"이라 verify_log.tsv row 6의 진단(§5-3과 §6-b 동시 적용
가능·정책 미확정)은 **타당하다 — 이것은 EN의 T-13/W-05(같은 접두어 내 순번 연장, 이미 §6(b)로
충분)와 근본적으로 다른 상황**이다. EN(F-EN-1)과 달리 SC는 실제로 결정요청이 필요하다.
