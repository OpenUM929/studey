**스캔 원본 렌더 규격 (판정 260903_04 A1 — 회전·다단 스캔 한정)**

`page.rotation` 은 콘텐츠 회전을 **알려주지 않는다** — `EX-social-20261M` 은 8쪽 전건 `rotation=0`
인데 콘텐츠는 90도 회전이었다. 메타데이터 기반 회전 판정은 원리상 실패하므로 **육안 확인**한다.

```python
imgs = page.get_images(full=True)
if len(imgs) != 1:                      # C-A1-2 fail-closed
    raise SystemExit('blocked: 임베드 이미지 %d개 — 첫 장만 쓰지 않는다' % len(imgs))
px = doc.extract_image(imgs[0][0])
dpi = round(px['width'] * 72 / page.rect.width)      # C-A1-3 계산값 (상수 금지)
im  = Image.open(io.BytesIO(px['image'])).rotate(ANG, expand=True)   # ANG 은 유닛별 실측
w, h = im.size                                        # 2단이면 겹침 분할, 1단이면 그대로
im.crop((0, 0, w//2+OV, h)).save('corpus/_images/<ID>/native/pNN_L.png')
im.crop((w//2-OV, 0, w, h)).save('corpus/_images/<ID>/native/pNN_R.png')
```

- **회전각·단 수·겹침·거터·실효 dpi 는 유닛별 실측값**이다. 상수로 적지 않는다.
- **C-A1-1** — 그 5개 값을 `meta.yml` 또는 `verify_log` 의 `transcribe` 행 `reason` 에 남긴다.
  기록이 없으면 그 렌더는 재현 불가이고, 재현 불가한 판독 이미지는 증거축을 잃는다
  (`docs/DATA_STANDARD.md` §5.7-A).
- **C-A2** — 정립·분할본은 반드시 `native/` **하위**에 둔다. `pNN.png` 와 같은 디렉터리에 두면
  G1 이 `pages=24` 를 세어 **분모가 깨진다**(판정자 실측). `verify_log` 의 `evidence` 는 어느
  이미지를 본 것인지 구분되게 적는다 — 예 `native/p03_R+상단` vs 기존 `p03+우단`.
- 정중앙 고정 분할은 금지다. 스큐가 있어 내용을 자른다 — 거터는 완전 백색 열 기준으로
  임계값과 함께 실측한다(**FA2**: `EX-social-20261M` p03 은 열 평균 밝기 최대 기준 1510,
  판정자의 백색열 계수 기준 25개 구간, 어느 측정이든 결론은 「정중앙 고정 분할 금지」로 같다).
- **C-A3-1 문항 머리 규칙** — 인쇄 선언된 **모든** 문항에 대해 갈래를 불문하고
  `### ` + 문항번호 + `.` 형태의 머리를 **정확히 1개씩** 낸다(예 `### 7.`).
  **미발견·절단 문항도 머리는 내고** 그 줄에 상태를 적는다. 이 규칙이 잡는 알려진 실패:
  `EX-social-20261M` 은 선택형 24개에만 머리를 내고 단답형 3개를 누락해
  `item_heads=24 declared_items=27` 이 된다(원칙 12-d).
- **E1-1 갈래 전환 줄 (필수)** — 서답형(단답형·서술형·서답형) 문항 머리가 시작되기 **전에**,
  갈래 토큰이 샵 바로 뒤에 오는 전환 줄(`## 단답형` / `## 서술형` / `## 서답형`)을 **정확히 1줄**
  둔다. **대괄호를 앞에 두면(`## [단답형1]`) 전환이 발화하지 않는다.**
  이 줄이 없으면 서답형 배점이 선택형으로 계상돼, **흠 없는 전사가 G2-a 에 걸린다**

  `## 단답형` 추가 PASS). 원인은 전사자의 잘못이 아니라 C-A3-1 문언의 결함이었고,
  판정자가 자기 조건의 결함으로 명시했다.
```

### S2 — 정제 게이트 (유닛별 · 원칙 11-a 분모는 원본)

**게이트 명령 — 표 안에 두지 않는다**(RF3). 아래를 **문면 그대로** 실행한다.
표 셀 안에서는 파이프를 이스케이프해야 하는데, 그 `\|` 가 ERE 안에서는 리터럴 파이프가 되고
셸에서는 `ls` 의 인자가 되어 **명령 자체가 깨진다**(판정 260903_02 RF1·RF2 실측).

```bash
U=<코퍼스ID>

# 접두어는 재열거하지 않고 카탈로그에서 런타임 유도한다 (원칙 9-c-ii)
PFX=$(grep -h '^## 유형 ' analysis/catalog/*.md | sed 's/^## 유형 //' \
      | grep -oE '^[A-Z]+[0-9]*' | sort -u | paste -sd'|' -)

img=$(ls corpus/_images/$U/*.png | wc -l);  echo "pages=$img"            # G1
f=$(ls corpus/$U/ | wc -l);                 echo "unit_files=$f"         # G3
n=$(grep -cE "\b($PFX)-[0-9]{2}\b" corpus/$U/transcript.md)
echo "typeid_hits=$n"                                                    # G4
present=$(grep -cE '^(transcribed_at|render_dpi|render_tool):' corpus/$U/meta.yml)
empty=$(grep -cE '^(transcribed_at|render_dpi|render_tool):[ \t]*(null|~)?[ \t]*(#.*)?$' corpus/$U/meta.yml)
echo "present=$present empty=$empty"                                     # G5

# G2-a — 이미 검출력이 실증된 자를 소비한다 (신규 검출기를 만들지 않는다)
python tools/measure_score_bands.py > /tmp/g2a.txt 2>&1; g2a=$?
echo "g2a_exit=$g2a"; grep -E "GATE 0 PASS|GATE 3|$U" /tmp/g2a.txt

# G2-b — 파싱을 산출 규격으로 바꾼다 (쓰는 쪽에 결정론을 요구한다)
heads=$(grep -cE '^### [0-9]+\.' corpus/$U/transcript.md)
decl=$(grep -E '^items:' corpus/$U/meta.yml | grep -oE '[0-9]+' | head -1)
echo "item_heads=$heads declared_items=$decl"
```

`PFX` 는 260904 실측 **13종**. 새 카탈로그가 생기면 자동으로 늘어난다 — 이 값을 본문에 적지 않는다.

| 축 | 수용기준 (위 출력 문자열로만 판정한다) |
|---|---|
| G1 쪽 수 | `pages=` 값이 아래 **G1 기대표**의 해당 ID 값과 일치 |
| G2 문항 수 | 아래 **G2 절** — 선언 = 전사, 차 **0** |
| G3 산출물 | `unit_files=3` |
| G4 분류 무침투 | `typeid_hits=0` 정확히 1줄 · 경고 0줄 |
| G5 meta | `present=3` **그리고** `empty=0` |
| G2-a 선언↔추출 | `[GATE 0 PASS] undetected=0` 1줄 · `[FAIL] GATE 3` 줄에 **`$U` 가 없다** |
| G2-b 머리↔선언 | `item_heads` 와 `declared_items` 가 **같다** |

> **C-A3-3 자 의존 (원칙 12-a·12-c).** G2-a 가 쓰는 `tools/measure_score_bands.py` 는
> `analysis/REV_GUIDE.md` §5 **two-key 대상**이다. 실행 레인은 **소비만** 한다 —
> G2-a 가 걸린다고 그 도구를 고치지 않고 **결정요청으로 올린다**. 그 도구가 바뀌면
> **이 게이트로 내린 통과 판정은 전부 stale** 이며 재실행 전까지 인용할 수 없다.
>
> **C-A3-4 수학 2유닛 커버리지 공백.** 도구 소스가 수학 계열의 선택형 축을 0으로 강제하므로
> `EX-math1-20261M` · `EX-math1-20261F` 는 **G2-a 의 실질 대상이 아니다.** 두 유닛은
> **G2-b 단독**으로 게이트된다. 「전건 통과」가 이 두 유닛에서 다른 의미를 갖는다는 뜻이다.
>
> **FA3 — G2-a 는 저장소 전체를 훑는다.** 다른 유닛의 결함까지 함께 실패시키므로,
> 유닛별 판정은 `[FAIL]` 줄에 **그 유닛 ID 가 포함되는지**로 한다(전체 exit code 가 아니라).

> **`grep -c` 의 종료코드를 읽지 마라.** 통과(0건) 시 exit 1, 실패(1건 이상) 시 exit 0 으로 **반전**된다
> (판정 260903_01 §1-D 실측). 판정은 오직 위 `echo` 출력 문자열로 한다.
