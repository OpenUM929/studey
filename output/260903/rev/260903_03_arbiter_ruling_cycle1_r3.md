# §1 독립 재검증

## §1-A 검증 설계 — 왜 패킷의 증명을 재사용하지 않았는가

패킷은 「문서에서 추출해 실행」하는 증명기를 만들어 썼다고 보고했고, 그 접근은 R2 판정의 지적에 정확히 대응한다. 그러나 **증명기가 문서를 옳게 추출했는지는 증명기 자신이 보증할 수 없다.** R2에서 문제가 된 것도 「문서 밖에서 잰 값」이었으므로, 판정자가 그 값을 받아 적으면 같은 사각이 한 겹 뒤로 옮겨질 뿐이다. 따라서 판정자는

1. PRD 원문에서 bash 펜스 블록을 **자체 정규식으로 추출**하고(추출본 원문을 아래에 옮겨 대조),
2. 저장소 밖 **자체 샌드박스**(카탈로그 실본 복사 + 판정자가 직접 심은 결함 유닛)를 구성하고,
3. 추출본에서 **`U=` 한 줄만 치환하고 나머지는 한 글자도 고치지 않은 채** `bash`로 실행했다.

추출 결과: PRD의 bash 펜스 블록은 **2개**이고, S2 게이트 블록은 첫 번째(749 B / 13줄)다. 추출본 원문:

```bash
U=<코퍼스ID>

# 접두어는 재열거하지 않고 카탈로그에서 런타임 유도한다 (원칙 9-c-ii)
PFX=$(grep -h '^## 유형 ' analysis/catalog/*.md | sed 's/^## 유형 //' \
      | grep -oE '^[A-Z]+[0-9]*' | sort -u | paste -sd'|' -)

img=$(ls corpus/_images/$U/*.png | wc -l);  echo "pages=$img"            # G1
f=$(ls corpus/$U/ | wc -l);                 echo "unit_files=$f"         # G3
n=$(grep -cE "\b($PFX)-[0-9]{2}\b" corpus/$U/transcript.md)
echo "typeid_hits=$n"                                                    # G4
present=$(grep -cE '^(transcribed_at|render_dpi|render_tool):' corpus/$U/meta.yml)
empty=$(grep -cE '^(transcribed_at|render_dpi|render_tool):[ \t]*(null|~)?[ \t]*(#.*)?$' corpus/$U/meta.yml)
echo "present=$present empty=$empty"                                     # G5
```

**이스케이프된 파이프가 하나도 없다.** R2에서 게이트를 무력화했던 원인이 문자 수준에서 사라졌다.

## §1-B 문면 그대로 실행 — 심은 결함 8/8 검출, 오탐 0/2

판정자가 심은 결함은 패킷의 fixture 집합과 **의도적으로 다르게** 구성했다. 특히 G4는 R1 원안이 놓쳤던 **세 가지 침투 형태**를 각각 별도 유닛으로 심었다(대괄호 형태 · 콜론 형태 · 맨 ID 형태). 오탐 유도 유닛도 넣었다.

| UNIT-OK | 결함 없음(정상 기준선) | 8 | 3 | 0 | 3 · 0 | **PASS** (수용기준 전건 충족) |
| UNIT-DPINULL | `render_dpi: null` | 8 | 3 | 0 | 3 · **1** | 검출 |
| UNIT-DPIEMPTY | 세 필드 모두 빈 값 | 8 | 3 | 0 | 3 · **3** | 검출 |

| UNIT-MISSING | `verify_log.tsv` 결손 | 8 | **2** | 0 | 3 · 0 | 검출 |
| UNIT-FPGUARD | 오탐 유도 문자열 | 8 | 3 | **0** | 3 · 0 | **오탐 없음** |

```
planted=8  detected=8  undetected=0
false_positive=0 / 2   (UNIT-OK · UNIT-FPGUARD)
```

- **UNIT-TYPEID 3종이 결정적이다.** R1 원안 G4는 리터럴 `유형 ` 선행을 요구해 이 세 형태를 전부 놓쳤다(0/13). v3 블록은 세 형태 모두 `typeid_hits=1`을 낸다 — 즉 수리가 접두어 목록만 고친 것이 아니라 **매칭 형태까지 고쳤음**이 실증됐다.
- **UNIT-FPGUARD**에는 `2026-01` · `p01-02` · `AB-12` · `ZZ-99`를 넣었다. 연도·페이지 범위 표기와 미등록 접두어가 오탐을 일으키지 않음을 확인했다(`typeid_hits=0`).
- **UNIT-OK가 통과한다는 사실이 R2와의 결정적 차이다.** R2의 G5a는 정상 유닛에도 `present=0`을 내어 수용기준이 도달 불가였다. v3는 `present=3 empty=0`으로 정확히 통과한다 — 게이트가 fail-closed이면서 **동시에 만족 가능**하다(원칙 12-a).

### transcript.md 결손 변형 — 패킷 주장 검증

패킷은 「`typeid_hits=`가 값 없이 나오고 경고 1줄이 뜨므로 수용기준 양쪽에서 막힌다」고 주장했다. 별도 유닛(`UNIT-NOTRANS`)으로 재현했다.

```
stdout : pages=8 / unit_files=2 / typeid_hits= / present=3 empty=0
stderr : grep: corpus/UNIT-NOTRANS/transcript.md: No such file or directory   (경고 1줄)
```

`typeid_hits=`는 수용기준 `typeid_hits=0`과 다르고, 경고가 1줄이라 「경고 0줄」 조건에도 걸리며, `unit_files=2`가 「3」과 다르다. **세 축에서 동시에 fail-closed다.** 패킷 주장은 정확하다.

- **원칙 12-d(검출력 증명)** → **충족.** 판정자가 심은 독립 fixture로 `planted=8 detected=8 undetected=0`, 오탐 유도 2건 통과. PRD 본문의 검출력 증명 표 기재값도 판정자 실측과 일치해 stale 주장이 없다.
