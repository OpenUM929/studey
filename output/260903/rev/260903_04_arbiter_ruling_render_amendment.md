## §1-A 렌더 결함 — 원본 메타 실측 (8쪽 전건)

```

rotations = [0, 0, 0, 0, 0, 0, 0, 0]
p01~p08  page_rect = 517 x 730 pt,  imgs = 1,  임베드 = (2150, 3035) mode=L jpeg   (8쪽 전건 동일)
```

- **실효 해상도**: 가로 2150 x 72 / 517 = **299.4 dpi**, 세로 3035 x 72 / 730 = **299.3 dpi**. 반올림 300 dpi. 개정안 기재와 일치한다.
- **현행 정제본**: dpi 160 → 517/72 x 160 = 1149, 730/72 x 160 = 1622. 개정안이 적은 `1149x1622`와 일치한다.
- **손실량 정정**: 160/300 = 0.533 이므로 **선형 53%를 남기고 47%를 버린 것**이다. 개정안의 「선형 53%를 버렸고」는 방향이 뒤집힌 표현이다. 결론(해상도 손실이 크다)에는 영향이 없으나 개정 반영 시 문구를 바로잡는다.
- **`page.rotation`은 8쪽 전건 0**이다. 개정안의 「메타데이터로는 안 보인다」가 실측으로 확인된다 — 회전 판정을 `page.rotation`에 의존하면 이 결함은 원리상 검출 불가다.
- **임베드 이미지가 페이지당 정확히 1개**임을 8쪽 전건 확인했다. 개정안 코드가 `get_images(full=True)[0][0]`을 쓰므로 이 전제는 유닛마다 검사해야 한다(조건 C-A1-2).

## §1-B 회전·2단 구조 — 판정자 직접 판독

확인된 사실:
- 정립 후 지면은 **가로 방향**이며 상단에 전폭 머리말(「통합사회1과 제 1학기 중간고사 문제지 / 제 1학년 2026년 4월 28일 3교시」)이 있고 그 아래가 **2단**이다.
- **좌단 = 문항 5**(「(가)~(다)에 나타난 문화 변동에 대한 옳은 설명만을 `<보기>`에서 있는 대로 고른 것은? [3.6점]」, (가)(나)(다) 자료 전문 + `<보기>` 시작부).
- **우단 = 문항 7**(「(가)~(마) 기후에 대해 정리한 학생 제출 답안의 점수는? [4점]」, `<기후 구분 흐름도>` 도표 전체 + 「학생 제출 답안」 1~4번 항목).
- 도표 내부 텍스트(「최한월 평균 기온이 18℃ 미만입니까?」 등)와 학생 필기까지 판독 가능하다.

**따라서 개정안의 핵심 주장 — 「미발견은 원본 결락이 아니라 둘째 단 판독 불가」 — 는 사실이다.** 회전 정규화 없이 dpi 160으로 세로 렌더한 이미지에서 이 내용을 읽어내는 것은 기대할 수 없다.

- **거터 위치**: 정립본을 그레이스케일 축소해 열별 평균 밝기를 재니 중앙부 최대 밝기 열이 **원본 좌표 1506** 이고 지면 중앙은 1517이다. 개정안의 `1510 / 3035`와 사실상 일치한다(측정 격자 차이).
- ⚠️ **개정안과 다르게 나온 값 1건(방법 차이, 결함 아님)**: 개정안은 「완전 백색 열 0개」라 했으나 판정자 측정(2배 축소 + 4행 샘플링, 임계 254.5)에서는 25개가 나왔다. 측정 방식이 다르므로 어느 쪽도 틀렸다고 하지 않는다. **어느 값이든 결론은 같다** — 완전 백색 열이 지면 정중앙에 있지 않으므로 50/50 고정 분할은 내용을 자른다. 개정안의 겹침 분할 설계는 이 사실에 정확히 대응한다.

## §1-C A3 — G2 계수법의 전수 실측

### (1) 개정안이 못 찾은 이유를 먼저 확인했다

**verify_log 축은 쓸 수 없다.** `transcribe` 행이 문항 단위가 아니라 **쪽 단위**로 기록돼 있다.

```
transcribe 행 수 == meta items 인 유닛 = 2 / 52
EX-social-20261M 의 27행 = 쪽 단위 transcribed 9행 + 문항 단위 unreadable 18행 (우연의 일치)
target 예: "p02(1~4번)" · "p08(단답형1,2)"
```

**transcript 문항 머리 축도 소급으로는 쓸 수 없다.** 레거시 전사본은 HWP 텍스트 덤프라 머리가 0개다.

```
'^### ' + 문항번호 + 마침표  규칙으로 items 와 일치하는 유닛 = 1 / 52
'^##' ~ '^####' + 문항번호 + 마침표  규칙                    = 0 / 52
```

즉 **기존 코퍼스를 소급 파싱해서 결정론적 계수를 얻는 방법은 없다.** 개정안이 「확정하지 못했다」고 한 것은 정확한 자기 진단이다.

### (2) 그러나 이미 존재하는 자가 이 사고를 잡았다

`tools/measure_score_bands.py`(REV_GUIDE §5 two-key 자·측정기)를 저장소에서 그대로 실행했다.

```
exit=1
[GATE 0 PASS] undetected=0            (planted=9 undetected=0 / planted-state=6 undetected=0)
=== GATE 3 declared: printed declaration vs extraction ===
[WARN] EX-social-20261M     declared n=24  extracted n=15
mismatches=1
[FAIL] GATE 3 mismatches=1 -- EX-social-20261M
```

- **이 도구는 새 유닛을 자동으로 모집단에 넣었고, 사람의 산문 독해 없이 먼저 잡았다.**
- GATE 3 모집단 = `rows` 전체 = **51유닛**이며, 소스 L237이 `decl is None`도 불일치로 계상하므로 **커버리지 51/51 fail-closed**다.
- 매 실행 자기검출력을 증명한다(`[GATE 0 PASS] undetected=0`) — 원칙 12-d 충족.
- **한계**: 소스 L131이 수학 계열을 `sod, sel, decl = sel+sod, [], 0`으로 강제하므로 수학 유닛은 선택형 축에서 항상 `0 == 0`으로 통과한다. 이번 사이클의 `EX-math1-20261M`·`EX-math1-20261F` 2유닛은 이 축의 실질 커버리지 밖이다.

## A1 — S1 렌더 규격을 스캔 원본에 한해 개정하는가 → **approve**

승인한다. 세 가지가 실측으로 확립됐다: (i) 원본은 299 dpi인데 정제본은 160 dpi로 선형 47%를 버렸다 (ii) `page.rotation`이 8쪽 전건 0인데도 콘텐츠는 90도 돌아가 있어 **메타데이터 기반 회전 판정은 원리상 실패한다** (iii) 정립하면 2단 지면이고, 판정자가 직접 읽어 둘째 단(문항 7)이 도표까지 온전함을 확인했다. 「미발견 7문항」은 원본 결락이 아니다.

개정안이 회전각·단 수·겹침을 **고정 상수가 아니라 유닛별 실측**으로 정하겠다고 한 것은 옳다. 그 원칙을 게이트가 강제하도록 조건을 붙인다.

### 조건 (구속)

- [ ] **C-A1-1 — 렌더 파라미터를 기록한다.** 유닛별로 실측한 `회전각` · `단 수` · `겹침 px` · `거터 x좌표` · `네이티브 실효 dpi`를 `meta.yml`(또는 `verify_log`의 `transcribe` 행 `reason`)에 남긴다. 기록이 없으면 그 렌더는 재현 불가이고, 재현 불가한 판독 이미지는 3중 증거축의 두 번째 축을 잃는다(`DATA_STANDARD` §5.7-A).
- [ ] **C-A1-2 — 임베드 이미지 개수를 fail-closed로 검사한다.** 개정안 코드는 `get_images(full=True)[0][0]`으로 **첫 이미지 1개만** 가정한다. 이 유닛은 8쪽 전건 1개임을 실측했으나 다른 유닛은 다를 수 있다. 개수가 1이 아니면 조용히 첫 장만 쓰지 말고 `▲ blocked`로 멈춘다(원칙 11).
- [ ] **C-A1-3 — `render_dpi`는 계산값을 적는다.** 「300」을 상수로 적지 말고 `임베드 가로픽셀 x 72 / 페이지 가로pt`로 산출한 값을 적는다(이 유닛은 299.4 → 299 또는 300). 상수 기입은 다음 유닛에서 반드시 어긋난다(원칙 9-c).

## A2 — G1 기대표를 어떻게 하는가 → **approve (나)**

**(나) 분할본을 하위 디렉터리에 두고 G1은 `pNN.png` 8장 기준을 유지한다.**

(가)를 채택하지 않는 이유가 결정적이다. **기대값을 「쪽수 x 단수」로 바꾸면 분모가 산출물에 종속된다.** 단 수는 원본을 판독해야 알 수 있고 표지는 1단, 본문은 2단처럼 쪽마다 다를 수 있으므로, 기대표를 렌더 이후에야 확정할 수 있게 된다. 그것은 원칙 11-a가 금지하는 형태 — 「분모를 산출물에서 잡으면 잘려나간 산출물이 만점을 받는다」 — 이며, **이번 사고가 정확히 그 형태로 일어났다.** 반면 (나)는 분모를 원본 쪽수에 묶어 두므로 이미 승인된 G1 기대표(원본 대조 10/10)가 그대로 유효하다.

## A3 — G2를 실행 명령으로 승격하는가 → **approve** (명령 형태는 판정자가 확정)

승인한다. 그리고 요청대로 **명령 형태를 판정자가 확정한다**(§1-C (3)). 확정의 근거를 남긴다.

**결정론은 파싱에서 오지 않는다.** 개정안이 계수법을 못 찾은 것은 능력의 문제가 아니라 사실의 문제다 — 실측 결과 verify_log는 쪽 단위이고(52유닛 중 2), 레거시 transcript는 머리가 0개다(52유닛 중 1). **자유 산문에서 문항 수를 소급으로 결정론적으로 세는 방법은 없다.** 그래서 확정안은 두 갈래로 간다.

1. **G2-a는 이미 있는 자를 쓴다.** `tools/measure_score_bands.py`는 인쇄 선언 대 추출 문항 수를 51/51 커버리지로 대조하고, 매 실행 자기검출력을 증명하며(`[GATE 0 PASS] undetected=0`), **이번 사고를 사람보다 먼저 잡았다**(`declared n=24 extracted n=15`). 새 검출기를 만드는 것보다 이미 검출력이 실증된 검출기를 쓰는 것이 원칙 12-d에 맞다.
2. **G2-b는 파싱 문제를 산출 규격 문제로 바꾼다.** 세는 쪽을 정교하게 만드는 대신 **쓰는 쪽에 결정론을 요구한다** — 이것이 원칙 12-b(자는 손이 아니라 코드가 만든다)의 적용이다.

### 조건 (구속)

- [ ] **C-A3-1 — S1 산출물 규격에 문항 머리 규칙을 넣는다.** 「인쇄 선언된 **모든** 문항에 대해 갈래를 불문하고 「`###` + 공백 + 문항번호 + 마침표」(예 `### 7.`) 형태의 머리를 정확히 1개씩 낸다. 미발견·절단 문항도 머리는 내고 상태를 그 줄에 적는다.」 현 유닛은 선택형 24개에만 머리를 냈고 단답형 3개를 누락해 `item_heads=24 declared_items=27`이 된다 — **이 규칙이 잡는 알려진 실패가 바로 그것이다**(원칙 12-d).

## A4 — `EX-social-20261M` 기존 산출물 처리 → **approve (가)**

근거는 규정과 판단 둘 다다.
