## 신규 두 세트 설계 방향 — 아직 문항/난도 판정 아님

1. 출력 추적 일변도 대신 **관측 결과에서 조건 역추론 → 후보 배제 → 다른 입력에서 검증**을 결합한다.
2. **상태 유지 조건 → 함수 부작용 → 반례/수정안 판별**처럼 앞 단계 결론이 뒤 단계에 필요한 구조를 사용한다.
3. **자료 변환 → 정보 손실 여부 → 조건을 만족하는 복구 가능성**을 연결하되, 교과서에서 확인한 범위 안에서만 쓴다.
4. 보안·정보윤리는 명칭 맞히기보다 제공된 규칙을 복수 제약에 적용하는 판단으로 설계한다. 범위 밖 법률 지식은 요구하지 않는다.
5. 각 문항은 기존26·현행A/B·기출·퀴즈와 가장 가까운 사례, 비수치 차이, 핵심 추론 차이를 기록한다. 코드 모양 차이만으로 신규성 PASS를 주지 않는다.
6. 최고난도는 기존 자의 기준으로 독립 평가한다. 긴 코드·많은 계산·낯선 문법으로 난도를 대신하지 않는다.
