## 2. 역할 계약을 진단 스키마로 전개

외부 `type-proposer` 계약 절차 1~8을 다음 검사 열로 분해했다. 이전 49건의 결함(문항행 수만 대사, 변형축·공통유형 대조·난이도 누락)을 반복하지 않기 위한 것이다.

1. `item_id`를 `W-01..W-04`, `S-01..S-18`로 단일 표기해 식별자 대사를 가능하게 한다.
2. 각 문항에 전사 행, 기존 유형 후보, 1차 생성군집, 형식축(A/B/C/D/E), 구조상 Tier, 근거/한계를 기록한다.
3. 군집은 “같은 단원 내용을 푼다”가 아니라 **새 문항을 만들 때 함께 바뀌는 변수·풀이 구조·오답 위험이 같은가**로 묶는다. 각 군집은 최소 두 변형축과 생성 금지/보류 조건을 가진다.
4. 기존 `SM2-nn`과 `C-nn`은 각각 과목 유형/공통 출제 문법으로 분리한다. 새 ID는 만들지 않고 후보/결정요청만 기록한다.
5. Tier는 답지·solve-back 없이 확정할 수 없으므로 `구조상 잠정 Tier`로만 표시한다. 서술형 10점은 현행 3.0~4.2점 Tier 환산이 정의돼 있지 않아 별도 보류한다.
6. 모든 22개 식별자가 정확히 한 번만 1차 군집에 들어가는지, 전사 행 증가 순서인지, BLOCKED가 생성 가능으로 승격되지 않았는지를 검증한다.

## 4. 생성 적합성 판정 규칙

- **조건부 생성 후보**: 전사 근거가 충분하고 기존 유형 또는 명확한 복합 규칙으로 설명되며, 변형축 2개 이상과 금지/함정이 적힌 군집.
- **보류**: 문항 구조는 읽히나 기존 유형과의 경계 또는 답/도형 의존성이 커서 Opus 판단이 필요한 경우.
- **BLOCKED**: 전사 자체의 미해결 부분이 유형 또는 풀이 조건을 바꾸는 경우. 이 상태에서는 유사문항 생성 금지.

이 규칙을 적용한 상세 표와 5개 군집은 `260828_02_codex_math2_diagnostic_analysis.md`에 있다. 조건부 생성 후보는 정본 유형의 사용 허가가 아니라, 외부 제안자가 검토할 가설이다.
