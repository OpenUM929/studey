## §0. 전송 상태 — 이 작업분은 이미 push됐다 (잔여 2경로)

이 문서 작성 집후 **동시 실행 중인 타 세션이 내 산출물을 커밌·푸시했다.**
상황이 바뀌었으니 초고의 「미커밌 11경로」 서술을 재실산으로 교체한다.

```
$ git log --oneline -8
79af2a2 chore: sync s9 gate report r6
...
836dca6 feat: update 260911 type-analysis records     <- 260911_03 · 260911_04 포함
4a9328b chore: refine EX-science verify logs          <- verify_log 2건
a92a80e chore: update 260910 cycle working records     <- WIP
$ git rev-list --count origin/main..HEAD
0                                                     # 커밌된 것은 전부 push 완료
```

| 경로 | 전송 | 판정 |
|------|------|------|
| `output/260911/260911_03_type_analysis_SC.md` | **push 완료** (`836dca6`) | 전송 불필요 |
| `output/260911/260911_04_catalog_update_SC.md` | **push 완료** (`836dca6`) | 〖 |
| `corpus/EX-science-20261{M,F}/verify_log.tsv` | **push 완료** (`4a9328b`) | 〖 |
| `analysis/wip/mainloop_260910_cycle1_propose2026.md` | 슬라이스 0~4는 push됨(`a92a80e`), **슬라이스 4-b·신 NEXT는 미커밌** | **전송 필요** |
| `output/260911/260911_06_continuation_plan.md` | **untracked** — 이 문서 | **전송 필요** |

→ **다른 PC로 넘길 것은 2경로만 남았다.** 커밌은 사용자 지시 시에만 하며,
이 세션은 커밌 이력이 0건이다. 타 배우 파일을 같은 커밌에 섞지 않는다(원칙 8):

```bash
git add analysis/wip/mainloop_260910_cycle1_propose2026.md         output/260911/260911_06_continuation_plan.md
git status --porcelain          # 스테이징 2경로만 남았는지 내 날이 아니라 증거로 확인
```

**주의 — 다른 세션이 같은 레포지토리를 쓰고 있다.** 이 문서 작성 중에만
커밌 8건이 들어왔다. 다른 PC 도착 직후의 첫 명령은 **`git pull`**이며,
작업 시작 전에 `git log --oneline -10`으로 **내가 알던 상태가 아지까지인지**를
한 번 더 재언기진다. WIP가 `status: in-progress`이면 규견 ②의 재개 경로가 걸린다
— **완료 슬라이스를 재수행하지 않는다.**

## §3. 한 유닛을 처리하는 고정 절차 (매 슬라이스 동일)

1. **무결성 동결** — `meta.yml`의 `items` 대 `transcript.md`의 `###` 머리 수를 세고 차이의 정체를
   설명한다(공유 발문 머리·비문항 소절은 문항이 아니다). 배점 합계도 센다 — 총점 불일치는
   「숫자가 틀렸다」가 아니라 **「문항이 빠졌다」**는 누락 검출기다(원칙 13-e).
2. **자 소비** — `python tools/measure_score_bands.py --per-item`에서 그 유닛 행만 읽어
   `Tier(자 r)` 열에 옮긴다. **손 채점 0건.** 값이 없는 유닛은 빈칸 + 결정요청.
3. **per-item 배정** — 카탈로그 `출제 빈도`를 옮겨 적는 것은 분류가 아니다. `transcript.md` 문면을
   다시 읽어 근거를 **`(주어진 것 · 요구 행동 · 풀이 골격)`** 3부로 적는다(원칙 13-d).
4. **`발상 DF5` 관측 열** — ●/◐/○. 자의 Tier를 대체하지 않고 병기한다.
5. **원칙 13(c) 수치 목록** — 「이 수를 다른 수로 바꿔도 같은 유형인가」가 **아니오**인 문항만
   따로 모아 적는다(그 수치는 유형 정보다). 나머지 수치는 관측만.
6. **유형 통합 + 변형 축** — BF2·BF3 적용(§4-3). **유형ID는 발부하지 않는다** —
   `## 유형 <미정>` + 임시 라벨(`NEW-XX-a`)까지만(원칙 9-a).
7. **원장 행** — 그 유닛 `verify_log.tsv`에 `classify`·`merge`·`grade`(+마감 시 `propose`) 8열 append,
   `actor` = `main-loop`. HARVEST_LOG·EXTRACTION_LOG는 **초안만 제안서에 싣고 실제 원장은 건드리지 않는다**
   (승인 전 `분석완료` 표시는 「반영 없이 재추출만 봉쇄」가 된다).
8. **WIP 한 행 + 게이트 펜스** — 슬라이스 끝마다 즉시 기록(규격 ②). WIP 삭제는 사용자만.
9. **자체 검출력 실증** — 게이트 블록에 「자체 검출 사례」를 적는다. 결함을 찾지 못한 검출기는
   검증되지 않은 검출기다(원칙 12-d).

## §4. 재개 시 반드시 아는 상태

### 4-1. 표준 게이트 문구 (제안서 말미에 그대로)

```
무결성     : 선언 N = 관측 N = 배정 N / duplicate 0 / missing 0 / extra 0
배점       : 선택형 합 + 서답형 합 = 100.0 (누락 검출기 — 원칙 13-e)
Tier       : 손 채점 0건 — measure_score_bands.py --per-item 소비값
발상 열    : ● x / ◐ y / ○ z = N
스코프 병기: `F-nn` 단독 인용 0건 (history·social 공유 접두어)
ID 발부    : 0건 (원칙 9-a)
```

## §5. 후속 사용자 지시 (분류 완료 후)

> 2024 & 2025 **1학년 2학기 중간고사**에서 **사회/국사 유형과 복합 유형**을 커버하는 **25제 세트 ×3**.

착수 전 확인해야 하는 것:

- **미해결 질문 2건** — ① 「25제씩 3개」가 총 3세트인가 과목별 3개(=6세트)인가
  ② 앞서 물었던 「남은 정제작업」의 분모. 사용자 답이 오면 그때 확정한다.
- **선행 조건**: 사회·국사 유닛 분류가 끝나야 유형 근거가 생긴다(슬라이스 5~7).
- **막혀 있는 것 — 회차 라벨(결정요청 ⓕ·ⓛ)**: 카탈로그의 회차 라벨은
  `24중간` `24기말` `25중간` `25기말` `26중간` `26기말` **6종뿐**이고,
  `english/science/social/history/korean.md`에서 **「2학기」 문자열은 0회**다.
  → **2학기 회차를 인용할 표기법이 없다.** 이 지시의 대상이 바로 2학기 중간고사이므로,
  **표기법 판정 없이는 「어느 유형이 그 회차에서 나왔다」를 카탈로그 문법으로 적을 수 없다.**
  세트 생성 자체는 가능하지만 근거 인용이 비규격이 된다 → 착수 시 사용자에게 먼저 상신한다.
- 세트는 생성 후 **두 게이트 필수**: `solve-back-verifier`(맹목 풀이) → `item-quality-auditor`(N/V/A 3축).
  게이트 통과 전 누구에게도 내놓지 않는다. `intended_use: practice|exam`을 frontmatter에 기록.
- **최고난이도 항목은 `DF5` 발상축을 실제로 켠다** — 「계산 단계 수를 늘린 것」은 이 지시의
  최고난이도가 아니다. 과학에서 실측된 발상 골격 4갈래를 재료로 쓴다:
  **① 역산**(결과 개수·면적·상댓값·패턴 → 원인) **② 조건 연립 특정**
  **③ 부호계·프레임 해독**(주기 대 코돈 3염기, 개시 프레임, ○/× 이진 매핑) **④ 이종 단원 교차**.

```python
def append_tsv(path, cells):
    raw = open(path, 'rb').read(); assert b'\r\n' not in raw
    txt = raw.decode('utf-8'); hdr = txt.splitlines()[0].split('\t')
    assert len(cells) == len(hdr)
    for c in cells: assert '\t' not in c and '\n' not in c
    body = txt if txt.endswith('\n') else txt + '\n'
    open(path, 'wb').write((body + '\t'.join(cells) + '\n').encode('utf-8'))
```
