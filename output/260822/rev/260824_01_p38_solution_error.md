**[문항 38번 본문]**

**38.** (서술형) 원 C: x² + y² − 2x + 12y + 28 = 0 을 직선 l: y = 2x − 3 에 대하여 대칭이동한 원을 C′이라 하고, 원 C′을 다시 x축에 대하여 대칭이동한 원을 C″이라 하자.

원 C″의 방정식을 구하는 과정을 서술하고, C″의 중심의 좌표를 (a, b), 반지름의 길이를 r이라 할 때 a + b + r 의 값을 구하시오.

⚠️ 부교재 근거 — 교육과정 명시 범위 초과

[SM2-32 · T3 · DF1·DF2·DF9]

**[정답표 38번 행 — 해설 셀 일부 발췌]**

> C: (x−1)²+(y+6)²=9, 중심 A(1,−6), r=3. 반지름은 대칭이동에서 불변이므로 중심만 옮기면 된다.
> A′(p,q)라 하면
> ① 중점 ((1+p)/2, (−6+q)/2)이 l 위: (−6+q)/2 = 2·(1+p)/2 − 3 ⇒ **q = 2p − 7**
> ② AA′ ⊥ l: (q+6)/(p−1) = −½ ⇒ p + 2q = −11.
> 연립하면 p=−3, q=−4 ⇒ A′(−3,−4). 이를 x축 대칭 ⇒ (−3, 4).
> C″: (x+3)²+(y−4)²=9, a+b+r = −3+4+3 = **4**.

제시 정답: **(x + 3)² + (y − 4)² = 9, a+b+r = 4** [SM2-32·T3]

<findings>
해설의 ①(중점 조건)에서 산출된 식 `q = 2p − 7`이 잘못되었다. 올바른 식은 `q = 2p + 2`다.

직선 l: y = 2x − 3 위에 중점 M((1+p)/2, (−6+q)/2)이 있으므로:

    (−6+q)/2 = 2·((1+p)/2) − 3 = (1+p) − 3 = p − 2      (양변 ×2)
    −6+q = 2p − 4   →   q = 2p + 2

검산 1 — 연립 결과 비교(sympy):
    q=2p+2 와 p+2q=−11 연립 → {p: −3, q: −4}   ← 제시된 A′(−3,−4)와 일치
    q=2p−7 와 p+2q=−11 연립 → {p: 3/5, q: −29/5} ← 제시 결과와 모순

검산 2 — 반사 공식 직접 대입(직선 2x − y − 3 = 0, 점 (1,−6)):
    k = (2·1 + (−1)(−6) + (−3))/(2²+(−1)²) = 5/5 = 1
    반사점 = (1 − 2·2·1, −6 − 2·(−1)·1) = (−3, −4) ✓

결론: 최종 답 A′(−3,−4), C″: (x+3)²+(y−4)²=9, a+b+r=4 는 정확하나,
해설 텍스트의 중간식 `q = 2p − 7`은 오기/대수 실수다. 학생용 해설로서는
①→② 연립 과정을 따라가는 학습자에게 모순을 노출시킨다.
</findings>
