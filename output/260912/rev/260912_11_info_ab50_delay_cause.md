## 질문과 결론
사용자가 보고한 15시간 이상 소모에도 왜 완료되지 않았는가?
직접 확인되는 원인은 **문항 완성이 아니라 주변 시스템의 정비를 다음 작업으로 계속 선택한 운영 오류**, 완료 증거의 재사용 실패, 그리고 요구 난이도와 실제 문항 설계의 불일치다. 사용자의 요구가 잘못됐기 때문이라고 돌리지 않는다. 15시간의 모델별 사용량·과금·작업별 소요 비율은 이 파일들로 계측할 수 없으므로 임의 수치로 설명하지 않는다.

## 삭제하는 현재 실행 절차 — 기록 파일은 삭제하지 않음
1. 전 과목60유닛의 재추출·영어/타 학기 점검을 **현재 제작 큐에서 제거**한다. 전역 기준 수리 잔여는 분리 보류한다. 기존 판정의 배포 게이트를 통과했다고 바꾸지 않는다.
2. B1–B3 재작성, BF1 명세 재개, 승인된 Q1의 변경 없는 전체 재시험 반복을 제거한다. 입력·후보가 달라졌거나 실제 적용 시에만 해당 검증을 다시 수행한다.
3. 현재 해시가 같은 문제의 답 대조50건·교과서33장 열람을 처음부터 다시 하는 절차를 제거한다. 변경된 문항/근거와 미완료 판단만 검토 대상으로 삼는다. 과거 증거의 모델·독립성 한계는 그대로 유지한다.
4. 이미 받은 정책 승인 재질문과 중간 산출물마다 세션 이동을 요구하는 절차를 제거한다. 실제 독립 감사 경계에서만 한 묶음을 인계한다.
5. ‘검수 중’ 단일 상태를 폐기한다. 답 정확성, 범위, 신규성, 요구 난이도, 인쇄, 최종 승인 각각의 완료·미완료를 따로 보고한다.
