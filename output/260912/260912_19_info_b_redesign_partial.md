def run(stock, jobs):

**11.** 개선한 배정 규칙이 실패하는 매개변수 (4점)

```python
def assign(x):
    jobs = [[4,7], [6,3], [5,x], [9,4]]
    load = [0,0]
    route = []
    for row in jobs:
        left = max(load[0]+row[0], load[1])
        right = max(load[0], load[1]+row[1])
        if left <= right:
            load[0] += row[0]
            route.append(0)
        else:
            load[1] += row[1]
            route.append(1)
    return [max(load), route]
```

x는 양의 정수이다. 각 작업은 장치 0 또는 장치 1 중 한 곳에서만 처리하며,
한 행의 두 수는 각각 그 장치에 작업을 배정할 때 증가하는 부하다.
다른 장치로 옮기거나 나누지 않는다. assign은 매번 그 작업까지 처리한 뒤의 최대 부하가 작은 쪽을 고른다.
최종 최대 부하를 최소화하는 배정은 중간 단계에서 더 큰 부하를 감수해도 된다.

def walk(a, start):

### 7. B/7 — 승인과 환급을 함께 고려한 초기 재고

**정답:** 최소 초기 재고 28. 순서는 E-B-C-A-D, E-B-C-D-A, B-E-C-A-D, B-E-C-D-A 네 개. 최종 재고 5.

**해설·중간 유도**

성공한 작업의 순손실은 E=1, B=2, C=12, A=4, D=4이며 항상 재고가 감소한다.
초기 재고가 27 이하라고 가정한다. C를 처리한 직후는 많아야 15이므로,
그때까지 E 또는 B가 남아 있으면 필요한 20 또는 17을 이후에도 확보할 수 없다.
따라서 E,B는 모두 C보다 앞서야 한다. 하지만 두 작업의 손실이 3이므로
C 직전 재고는 많아야 24여서 C를 승인할 수 없다. 초기 재고 27 이하는 불가능하다.
28이면 E→B 처리 시 28→27→25, B→E이면 28→26→25이고 C 후 13이 된다.
A,D는 순서와 무관하게 13→9→5로 승인된다. 따라서 하한 28을 달성한다.
28에서도 C 후에는 많아야 16이므로 E,B를 뒤로 보낼 수 없다.
E,B 외에 A나 D까지 C 전에 놓으면 손실이 최소 7이라 C 직전이 21 이하가 된다.
결국 E,B가 처음 두 자리, C가 세 번째이며 나머지 두 순서만 가능하다.
총손실 23만으로 초기값을 23이라고 답하면 환급 전 승인 문턱을 놓친다.

### 11. B/11 — 개선한 배정 규칙이 실패하는 매개변수

**정답:** 실패 x=3,4,5. assign의 최종값은 각각 10,11,12이고 최적값은 모두 9, 차이는 1,2,3. x=1의 최적값은 8; x≥2의 최적값은 9.

**해설·중간 유도**

처음 두 배정은 항상 0,1이고 부하는 [4,3]이다.
세 번째 작업을 0에 넣으면 최대 9, 1에 넣으면 max(4,3+x).
따라서 x≤5면 1, x≥6이면 0을 택한다. x=6 동점은 코드의 <= 때문에 0이다.
x≤5인 경우 [4,3+x]에서 마지막 작업을 0에 넣으면 최대 13,
1에 넣으면 7+x≤12라서 1을 택한다. 결과는 7+x, 경로 [0,1,1,1].
x≥6이면 세 번째 뒤 [9,3], 마지막은 1이므로 최대 9, 경로 [0,1,0,1].
전역 하한: 최대 부하가 8 이하인 배정에서는 마지막 작업은 0에 놓을 수 없어 1이다.
첫 작업까지 1이면 장치1 부하가 이미 7+4=11이므로 첫 작업은 0이다.
둘째 작업은 0에 두면 4+6=10이므로 1, 셋째는 0에 두면 4+5=9이므로 역시 1이다.
따라서 최대 8 이하가 가능하려면 [0,1,1,1]뿐이고 부하가 [4,7+x]이므로 x=1만 된다.
최대 7 이하 역시 같은 강제 배정에서 7+x≥8이므로 불가능하다.
x=1은 최대 8을 달성하고, x≥2는 [0,1,0,1]이 [9,7]을 만들어 하한 9를 달성한다.
이 최적값과 규칙의 두 구간을 대조하면 실패는 정확히 3,4,5이다.
작업 시간이 커질수록 규칙이 계속 나빠질 것이라는 추측은 x=6의 배정 전환 때문에 틀린다.

**채점 기준(4점)**
- 세 번째 배정의 x≤5/x≥6 분기와 동점 처리를 도출: 1점
- 규칙의 두 경로·최종값을 마지막 작업까지 유도: 1점
- 최대 8 이하라는 가정에서 배정을 강제하여 전역 하한 입증: 1점
- 최적 배정 달성과 실패 x·차이 및 나머지 구간을 정확히 대조: 1점

**유형·비교:** IN-15 + IN-22 + IN-13 + IN-04. 기존 B/11의 극단적인 두 작업 반례와 비교. IN-22의 2차원 행 순회와 IN-13의 최대값 및 IN-04 분기. 최고 원천 비교는 미확인.

### 18. B/18 — 두 시작점의 방문 요약으로 점프표 복원

**정답:** 유일한 a=[2,2,2,2,1,2,1,1,1,1]. 방문 목록은 [0,2,4,5,7,8,9]와 [1,3,5,7,8,9].

**해설·중간 유도**

시작 0의 실행은 0~9의 열 칸 중 세 칸을 건너뛴다. 전체 인덱스합 45에서 35를 빼면
건너뛴 세 칸의 합은 10이다. 점프가 최대 2이므로 건너뛴 칸은 서로 이웃하지 않고 0도 아니다.
합 10인 서로 다른 양의 정수 세 개를 빠짐없이 나열하면 {1,2,7},{1,3,6},{1,4,5},{2,3,5}이며,
실제로 이웃 금지를 만족하는 것은 {1,3,6}뿐이다. 따라서 첫 방문 목록이 확정된다.
다음 방문과의 차에서 a₀=2,a₂=2,a₄=1,a₅=2,a₇=1,a₈=1이고,
마지막 9에서 종료 인덱스 10이므로 a₉=1이다.
미정은 a₁,a₃,a₆ 세 칸이다. 이미 2가 세 개이므로 미정 중 정확히 두 개가 2이다.
시작 1의 경로는 a₁=1이면 1→2→4→5→7→8→9로 7회라서 관측 6회와 모순이다.
따라서 a₁=2로 1→3. a₃=1이면 1→3→4→5→7→8→9로 역시 7회이다.
a₃=2이면 1→3→5→7→8→9로 6회, 합33, 종료10을 모두 만족한다.
따라서 a₆=1이다. 두 실행 모두 6을 방문하지 않으므로 마지막 값은 개수 조건으로 정해진다.
두 번째 관측의 total=33은 나머지 관측에서 이미 따라오는 중복 검산값이다. 이를 독립적인 난도 조건으로 세지 않는다.

**채점 기준(4점)**
- 첫 실행의 건너뛴 칸 합10과 인접 금지로 방문 목록을 빠짐없이 확정: 1점
- 방문 간격 및 종료 인덱스로 7개 칸의 값 확정: 1점
- 둘째 실행의 6회 조건으로 a₁=a₃=2를 강제: 1점
- 미방문 a₆을 전체 개수로 확정하고 두 관측 대조·유일성 설명: 1점

**유형·비교:** IN-08 + IN-09 + IN-06. 기존 B/18의 증가량 양수·n회 상한 한 관찰을 대체. IN-08 조건/갱신 변수 분리와 IN-09 인덱스·IN-06 누적 대상. 최고 원천 비교는 미확인.

**비수치 변형:** 갱신 변수와 조건 변수: 미지 리스트가 결정하는 위치 이동; 출력식: 두 시작점의 방문 횟수·인덱스합·종료 위치로 역추적.

**작성자 설계·최단 풀이 점검:** 최단 풀이: 누락 방문의 합과 비인접 제약 → 위치별 점프 복원 → 두 시작점의 경로 합류 → 미방문 값의 개수 제약. 최종 종료 위치만으로 각 점프가 복원된다는 오독을 차단한다. 인덱스합33은 중복 관측임을 숨기지 않는다.
