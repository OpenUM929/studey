| D4 | **(p + 1)² + (q − 2)² = 9** | SM2-28+24 · 자취 | 평행이동한 원의 중심은 (1 + p, −2 + q)이고 반지름은 **불변**인 2. 원 D는 중심 (0, 0), 반지름 1. 외접 ⇔ 중심거리 = 2 + 1 = 3이므로 (1 + p)² + (−2 + q)² = 9, 즉 **(p + 1)² + (q − 2)² = 9**. / 함정: 평행이동으로 **반지름이 변한다고 착각**. 외접을 \|2 − 1\| = 1(내접 조건)로 잘못 세움. 답을 점 하나로 구하려 함 — 조건을 만족하는 (p, q)는 **원 위의 무수히 많은 점**이다. |
| D5 | **5** | SM2-21+20 · 결합 | P(1, 2)는 원 위의 점이므로 접선 *l*은 x·1 + y·2 = 5, 즉 x + 2y = 5. *l*의 기울기가 −1/2이므로 이에 수직인 직선 *m*의 기울기는 2이고 원점을 지나므로 y = 2x. *l*과 *m*의 교점은 P(1, 2)이고, *l*의 x절편은 (5, 0), *m*의 x절편은 원점이다. 세 꼭짓점 (0,0), (5,0), (1,2)에서 넓이 = ½ × 5 × 2 = **5**. / 함정: 접선을 구할 때 **원점 중심 공식을 쓰지 못하고 판별식으로** 우회. *m*이 원점을 지난다는 조건을 빠뜨려 직선이 미결정. |
| D6 | **x − 8y + 2 = 0**, **32x + 4y − 1 = 0** | SM2-12 · 모두 구하기 | 각의 이등분선 위의 점은 두 직선에서 같은 거리에 있다. \|3x − 4y + 1\|/5 = \|5x + 12y − 3\|/13 → 13(3x − 4y + 1) = ±5(5x + 12y − 3). **(+)**: 39x − 52y + 13 = 25x + 60y − 15 → 14x − 112y + 28 = 0 → **x − 8y + 2 = 0**. **(−)**: 39x − 52y + 13 = −25x − 60y + 15 → 64x + 8y − 2 = 0 → **32x + 4y − 1 = 0**. / 함정(카탈로그 명시): **± 두 해 중 하나만 답함**. 분모를 5, 13으로 각각 나누지 않고 통분 실수. 두 이등분선이 서로 수직임을 검산에 쓰면 좋다(기울기 1/8과 −8). |
| D7 | **x² + y² − 4x − 6y = 0**, 중심 **(2, 3)** | SM2-15+01 · 외심 | ∠A = 90°인 직각삼각형이므로 **빗변 BC가 지름**이고 외심은 **빗변의 중점**이다. 중심 = ((4 + 0)/2, (0 + 6)/2) = **(2, 3)**, 반지름 = ½√(4² + 6²) = √13. 따라서 (x − 2)² + (y − 3)² = 13, 전개하면 **x² + y² − 4x − 6y = 0**. / 함정(카탈로그 지적): 중심을 (a, b) 두 미지수로 두고 세 방정식을 연립해 **계산량 폭증**. 원점을 지나므로 상수항이 0임을 이용하면 검산이 된다. |

## 서술형 채점 기준

### B1 [6점]
- 사각형 ABCD의 대각선이 **AC와 BD**임을 지적 … 2점
- 학생이 짝지은 AB, CD는 대각선이 아니라 **변**임을 명시 … 1점
- AC의 중점 (4, 6), BD의 중점 (4, 6)을 각각 계산 … 2점
- **평행사변형이다**라고 결론 문장을 씀 … 1점 (결론 누락 시 0점)

### C9 [6점]
- 평행이동은 x 대신 **x − 2**를 대입함을 명시 … 2점
- y = f(x − 2) … 1점
- y축 대칭은 x 대신 **−x**를 대입함을 명시 … 1점
- **순서대로** 적용하여 y = f(−x − 2) … 2점 (순서를 바꿔 f(−x + 2)로 쓰면 이 항목 0점)

### D4 [7점]
- 평행이동한 원의 중심 (1 + p, −2 + q) … 1점
- **반지름은 불변으로 2**임을 명시 … 1점
- 외접 조건을 중심거리 = 2 + 1 = 3으로 세움 … 2점
- (1 + p)² + (−2 + q)² = 9 … 2점
- 구하는 도형이 **중심 (−1, 2), 반지름 3인 원**임을 밝힘 … 1점

### D6 [7점]
- 각의 이등분선 = 두 직선에서 **같은 거리**인 점의 자취임을 서술 … 2점
- \|3x − 4y + 1\|/5 = \|5x + 12y − 3\|/13을 세움 … 2점
- 절댓값을 **± 두 경우로** 나눔 … 1점 (한 경우만 쓰면 이 항목과 아래 1점 모두 0점)
- x − 8y + 2 = 0 … 1점
- 32x + 4y − 1 = 0 … 1점

### D7 [7점]
- ∠A = 90°인 **직각삼각형**임을 확인 … 2점
- **빗변 BC가 지름**(또는 외심 = 빗변의 중점)이라는 성질을 서술 … 2점
- 중심 (2, 3) … 1점
- 반지름 √13 … 1점
- 방정식 x² + y² − 4x − 6y = 0 … 1점
