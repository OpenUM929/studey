이동한 원의 중심을 (t, s)라 하면 t = 1 + p, s = 3 + q이고 반지름은 불변인 2. y축에만 접하므로 |t| = 2이고, 제2사분면이므로 t < 0에서 t = −2. 중심이 y = x + 5 위이므로 s = 3. 따라서 p = −3, q = 0이고 p + q = −3. / 함정: 양축 접으로 오독해 |t| = |s|를 강제. 사분면 조건을 쓰지 않아 t = 2까지 답함. 평행이동에서 반지름이 변한다고 착각. / 260830 보완(게이트): 발문이 "y축에만 접한다"이므로 x축에 접하지 않음도 확인해야 조건이 닫힌다 — 중심의 y좌표 3과 반지름 2가 다르므로 x축에는 접하지 않는다 ✓
D7.x + y − 6 = 0SM2-12
각의 이등분선 위의 점은 두 직선에서 같은 거리에 있고, 두 직선의 법선 크기가 모두 √5로 같으므로 |x − 2y + 3| = |2x − y − 3|. (+) x − 2y + 3 = 2x − y − 3 → x + y − 6 = 0. (−) x − 2y + 3 = −2x + y + 3 → 3x − 3y = 0 → y = x. 원점을 대입하면 앞의 것은 −6 ≠ 0(지나지 않음), 뒤의 것은 0 = 0(지남). 따라서 x + y − 6 = 0. / 함정(카탈로그 명시): ± 두 경우 중 하나만 구하고 끝냄. 배제 조건("원점을 지나지 않는")을 무시하고 둘 다 답함.
