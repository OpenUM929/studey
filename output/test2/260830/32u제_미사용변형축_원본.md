| D7 | **x + y − 6 = 0** | SM2-12 | 각의 이등분선 위의 점은 두 직선에서 같은 거리에 있고, 두 직선의 법선 크기가 모두 √5로 같으므로 \|x − 2y + 3\| = \|2x − y − 3\|. **(+)** x − 2y + 3 = 2x − y − 3 → **x + y − 6 = 0**. **(−)** x − 2y + 3 = −2x + y + 3 → 3x − 3y = 0 → y = x. 원점을 대입하면 앞의 것은 −6 ≠ 0(지나지 않음), 뒤의 것은 0 = 0(지남). 따라서 **x + y − 6 = 0**. / 함정(카탈로그 명시): **± 두 경우 중 하나만** 구하고 끝냄. 배제 조건("원점을 지나지 않는")을 무시하고 둘 다 답함. |

## 서술형 채점 기준

### D3 [6점]
- 두 점이 직선에 대하여 대칭이면 그 직선은 **수직이등분선**임을 서술 … 2점
- 중점 (4, 2)를 구함 … 1점
- 직선 AB의 기울기 3/2에서 *l*의 기울기 −2/3을 구함 … 2점
- 2x + 3y − 14 = 0 … 1점

### D4 [7점]
- 두 식을 변끼리 빼면 이차항이 소거된다는 근거 서술 … 1점
- 공통현 x = 3 … 2점
- 두 교점 (3, 4), (3, −4) … 2점
- 지름의 양 끝점이므로 중심은 중점, 반지름은 절반임을 서술 … 1점
- (x − 3)² + y² = 16 … 1점

### D5 [7점]
- 평행이동 −3은 x 대신 **x + 3**을 대입함을 명시 … 2점
- x축 대칭은 y 대신 **−y**를 대입함을 명시 … 1점
- g(x) = −f(x + 3)을 얻음 … 2점
- x 대신 x − 3을 넣어 **방향을 뒤집음** … 1점
- f(x) = −g(x − 3) … 1점

### D7 [7점]
- 각의 이등분선 = 두 직선에서 같은 거리인 점의 자취임을 서술 … 2점
- 두 직선의 법선 크기가 같음을 확인하고 \|x − 2y + 3\| = \|2x − y − 3\|을 세움 … 2점
- **± 두 경우로 나눔** … 1점 (한 경우만 쓰면 이 항목과 아래 1점 모두 0점)
- 두 이등분선 x + y − 6 = 0, y = x를 모두 구함 … 1점
- 원점 대입으로 선별하여 x + y − 6 = 0 … 1점
