## 인쇄 방법

브라우저(Chrome/Edge)에서 HTML을 열고 **인쇄(Ctrl+P)** → 용지 **A4**, 배율 **100%**,
여백 **없음**, "배경 그래픽" 켜기. 페이지는 문서 안에서 이미 확정돼 있으므로
브라우저의 자동 분할이 개입하지 않는다.

## A4 배치 규칙 (사용자 요구, 260830)

1. **한 문항은 두 페이지에 걸쳐 쪼개지지 않는다.**
2. **문항의 시작 위치가 본문 영역의 80%보다 아래면 그 문항은 다음 페이지로 넘긴다.**

CSS `break-inside: avoid`로는 (2)를 표현할 수 없다. 그래서 페이지 배치는
문서를 열 때 JS가 **실제 렌더 높이를 재서** 확정한다(`_build_print.py`의 `JS` 블록).
섹션 제목이 문항 앞에 붙는 경우 제목 높이까지 포함해 "문항이 실제로 시작할 y"로 판정한다.

지면 규격: A4 210×297mm · 여백 상 16 / 좌우 15 / 하 14mm · 본문 영역 180×267mm
· 80% 경계 = 본문 상단에서 213.6mm 지점.
