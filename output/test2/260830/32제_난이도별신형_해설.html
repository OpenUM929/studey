AP + PQ + QB = A′P + PQ + QB′ ≥ A′B′ = √((−1 − 5)² + (2 + 4)²) = √72 = 6√2. 등호는 A′, P, Q, B′가 그 순서로 한 직선 위에 있을 때 성립한다 — 선분 A′B′ 는 y = −x + 1 이므로 x축과 (1, 0), y축과 (0, 1) 에서 만나고, A′에서 출발해 x축(P)을 먼저, y축(Q)을 나중에 지난다. 즉 P(1, 0), Q(0, 1)에서 실제로 달성된다. / 함정: 한 점만 대칭시켜 두 번 꺾이는 경로를 처리하지 못함. 대칭축을 서로 바꿔 적용(A는 x축, B는 y축이어야 한다). 부등식의 하한을 구하고 등호 성립을 확인하지 않음 — A′B′ 가 두 축을 지나는 순서가 요구된 순서와 반대이면 그 하한은 도달 불가이고, 그때 최솟값은 다른 값이 된다(이 문항의 260830 정정 사유).
D4.(p + 1)² + (q − 2)² = 9SM2-28+24 · 자취
평행이동한 원의 중심은 (1 + p, −2 + q)이고 반지름은 불변인 2. 원 D는 중심 (0, 0), 반지름 1. 외접 ⇔ 중심거리 = 2 + 1 = 3이므로 (1 + p)² + (−2 + q)² = 9, 즉 (p + 1)² + (q − 2)² = 9. / 함정: 평행이동으로 반지름이 변한다고 착각. 외접을 |2 − 1| = 1(내접 조건)로 잘못 세움. 답을 점 하나로 구하려 함 — 조건을 만족하는 (p, q)는 원 위의 무수히 많은 점이다.
D5.5SM2-21+20 · 결합
P(1, 2)는 원 위의 점이므로 접선 l은 x·1 + y·2 = 5, 즉 x + 2y = 5. l의 기울기가 −1/2이므로 이에 수직인 직선 m의 기울기는 2이고 원점을 지나므로 y = 2x. l과 m의 교점은 P(1, 2)이고, l의 x절편은 (5, 0), m의 x절편은 원점이다. 세 꼭짓점 (0,0), (5,0), (1,2)에서 넓이 = ½ × 5 × 2 = 5. / 함정: 접선을 구할 때 원점 중심 공식을 쓰지 못하고 판별식으로 우회. m이 원점을 지난다는 조건을 빠뜨려 직선이 미결정.
D6.x − 8y + 2 = 0, 32x + 4y − 1 = 0SM2-12 · 모두 구하기
각의 이등분선 위의 점은 두 직선에서 같은 거리에 있다. |3x − 4y + 1|/5 = |5x + 12y − 3|/13 → 13(3x − 4y + 1) = ±5(5x + 12y − 3). (+): 39x − 52y + 13 = 25x + 60y − 15 → 14x − 112y + 28 = 0 → x − 8y + 2 = 0. (−): 39x − 52y + 13 = −25x − 60y + 15 → 64x + 8y − 2 = 0 → 32x + 4y − 1 = 0. / 함정(카탈로그 명시): ± 두 해 중 하나만 답함. 분모를 5, 13으로 각각 나누지 않고 통분 실수. 두 이등분선이 서로 수직임을 검산에 쓰면 좋다(기울기 1/8과 −8).
D7.x² + y² − 4x − 6y = 0, 중심 (2, 3)SM2-15+01 · 외심
∠A = 90°인 직각삼각형이므로 빗변 BC가 지름이고 외심은 빗변의 중점이다. 중심 = ((4 + 0)/2, (0 + 6)/2) = (2, 3), 반지름 = ½√(4² + 6²) = √13. 따라서 (x − 2)² + (y − 3)² = 13, 전개하면 x² + y² − 4x − 6y = 0. / 함정(카탈로그 지적): 중심을 (a, b) 두 미지수로 두고 세 방정식을 연립해 계산량 폭증. 원점을 지나므로 상수항이 0임을 이용하면 검산이 된다.
