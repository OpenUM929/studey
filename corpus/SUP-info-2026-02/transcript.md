## p01 — Part 1 「변수와 리스트」

- 변수 : 변하는 수 / 값을 담는 공간 / 모든 변수는 이름이 필요하다
- 리스트 : 변수의 모음 / 0부터 숫자(index)로 구분 / 모든 리스트는 이름이 필요하다

| 좌 | 우 |
|---|---|
| `num1 = 1` / `num2 = 2`  일일이 다 만들어야 하잖아! / `num3 = 3` | `num = [ 1, 2, 3, 4, 5 ]` / `num[0], num[1]` 이렇게 쓸 수 있다! / `print(num[3])` = (빈칸) |

```
food = ["피자", "떡볶이", "김밥", "불고기", "마라탕"]
```
리스트의 특징 - 여러 개의 자료를 저장할 수 있다. 숫자, 문자열 등을 저장할 수 있다.
자료에는 순서가 있다. 각 자료는 인덱스(index) 를 이용하여 접근한다. 인덱스는 0부터 시작한다.

**문제** (답란은 모두 `<_답:        >` 형식의 빈칸)
```
a = [10, 20, 30, 40, 50]
a[0]        -> <_답:      >
a[2]        -> <_답:      >
a[4]        -> <_답:      >
a[1] + a[3] -> <_답:      >
a[1:]       -> <_답:      >
```

```
#입력받을 때
input().split()
["10", "20", "30"] #10 20 30 입력시 입력값 문자열로 저장
a = list(map(int, input().split())) # 공백으로 구분하여 입력한 여러 숫자를 정수로 변환한 뒤 리스트로 저장
```

**리스트 함수**

| 명령어 | 설명 |
|---|---|
| append(자료) | 리스트의 마지막에 자료 추가 |
| insert(인덱스, 자료) | 원하는 위치에 자료 추가 |
| remove(자료) | 리스트에서 해당 자료 삭제 |
| sort() | 리스트를 오름차순으로 정렬 |
| len(리스트) | 리스트의 자료 개수 |

```
food = ["피자", "떡볶이", "김밥"]
food.append("치킨")
print(food) -> <_답:        >
food = ["피자", "떡볶이", "김밥"]
food.insert(1, "치킨")
print(food) -> <_답:        >
food = ["피자", "떡볶이", "김밥"]
food.remove("떡볶이")
print(food) -> <_답:        >
```

**Part 3 — 세상에서 제일 매력적인 조건 구조**
- 어떤 조건에 따라서 명령어가 나누어지는 형태
- *게임에서 방향키를 눌렀을 때 캐릭터가 움직이는 것*을 조건 구조로 만들 수 있음

| 기본 형태 | 명령? |
|---|---|
| `if 조건 :` / `    if 조건이 만족했을 때 명령어`  <u># 반드시 콜론 후 들여쓰기</u> / `elif 조건 :` / `    if 조건이 아니고 다음 조건을 만족했을 때 명령어` / `else :` / `    위의 모든 조건이 만족하지 않았을 때 명령어` | 프로그래머가 프로그래밍을 통해 컴퓨터가 어떤 동작을 하게 하는 것을 '명령한다'라고 함. / 간단하게 키보드를 입력하는 것도 컴퓨터에게 명령을 하는 행동으로 볼 수 있음 |

```
sum = 10
if sum > 10:
    print("10보다 크다!")
elif sum>5:
    print("5보다 크다!")
else :
    print("작은 숫자다!")
```

| 0 | 90 | 80 | 70 |

| 2 | 100 | 90 | 80 |
