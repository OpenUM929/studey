② 이 점을 지나는 수직선은 x=0인데 원점과의 거리가 0이므로 탈락.
③ y = mx-2, 즉 mx-y-2=0의 원점 거리 = |-2|/√(m²+1) = 1 → m²+1 = 4 → **m = ±√3**.
④ **y = √3x - 2, y = -√3x - 2** (즉 √3x-y-2=0, √3x+y+2=0).
**함정** (260901 정정) 다발의 수직선 성분을 기계적으로 포함시키면 오답이다 — 이 문제에서는 x=0의 원점 거리가 0이라 탈락한다. v3의 `k=5±8√3/3`은 이 문제에 존재하지 않는 문자로 쓰인 값이었다.

### 2-16 — 3a+5b = -3

### 2-18 — 정수 합 = -15 (케이스 ①) / -21 (케이스 ②) ⚠️ 원문 경계 미명시 · **두 케이스 모두 보존**
> ⚠️ **이 문항은 답이 유일하게 고정되지 않는다.** 원문 「두 점 A, B **사이**를 지나도록」이 경계 포함 여부를 명시하지 않고, 도표(p07)에도 경계 정보가 없다. 원자료가 부교재라 인쇄된 정답이 없어 **복원할 정답 자체가 존재하지 않는다** — 교사 판정 사안이다. 사용자 지시(260902)에 따라 **어느 쪽도 폐기하지 않고 두 케이스를 모두 보존**한다.
> **고1 수준에서도 실제로 갈린다.** 학교에서 가르치는 두 표준 해법이 경계를 다르게 처리하기 때문이며, 학생이 어느 해법을 익혔느냐로 답이 바뀐다. 과잉 우려가 아니라 이 문항의 구조적 결함이다.
공통 부분: 정점 (-2,1) 다발, A(-1,4)로의 기울기 3, B(4,-1)로의 기울기 -1/3, 직선의 기울기 m = -a/2 → **-6 < a < 2/3** (경계 판단 전 공통 범위).

**케이스 ① — 개구간, 합 = -15** *(원문 표현에 더 충실)*
- 해법: **부호 판별** — A와 B가 직선의 **서로 다른 쪽**에 있어야 하므로 `f(A)·f(B) < 0` (순부등호). f(x,y)=ax+2y+2a-2.
- 정수 a = -5, -4, -3, -2, -1, 0 → **합 -15**.
- 근거 (i) 「사이」는 두 점의 **분리**를 뜻한다 — 직선이 A를 지나면 A는 **직선 위의 점**이지 사이에 있는 것이 아니다(f(A)=0이라 부호곱이 0).
- 근거 (ii) **이 자료 자신의 관행** — 같은 답지 `4-9`는 원문이 「**만난다**」이고 답이 `1/2 ≤ k ≤ 9/2`로 **등호를 포함**한다. 카탈로그 `SM2-28`도 「"만난다"에 접함이 포함되어 등호(≤)」로 적었다. 즉 이 자료는 **등호를 원할 때 「만난다」라고 쓴다.** 2-18은 「만난다」가 아니다.
- 근거 (iii) 두 해석의 차이는 **a = -6 하나뿐**이다(B쪽 끝값 a=2/3은 정수가 아니라 애초에 후보가 아니다). 경계에 정수 하나만 얹힌 비대칭은 등호 처리를 묻는 함정으로 읽힌다.
- 근거 (iv) **원문 도표**(260902 p07 우하 재대조) — 그림의 직선은 A도 B도 **지나지 않고** 둘 사이를 통과하게 그려있다(A는 수직 점선, B는 수평 점선으로만 표시되고 직선은 그 사이를 가로질러 지나간다). 도표는 한 예시 위치일 뿐이라 단독으로 경계를 확정하지는 못하지만, 출제자가 그린 상태는 **분리(개구간)** 쪽이다.

**케이스 ② — 폐구간, 합 = -21** *(「선분 AB와 만난다」로 읽었을 때)*
- 해법: **정점 + 기울기 범위** — `-1/3 ≤ -a/2 ≤ 3`, 등호 포함.
- 정수 a = -6, -5, -4, -3, -2, -1, 0 → **합 -21**.
- 근거: a=-6이면 직선은 y=3x+7로 A(-1,4)를 **정확히 통과**하는데, 「선분과 만난다」로 읽으면 끝점 통과도 만나는 것이다. 고1에서 「선분 AB와 만나도록」 유형은 **등호를 포함해** 가르치므로 이 경로로 -21을 내는 학생이 적지 않다.

**지도 요령** 채점 정답을 어느 쪽으로 정하든, **반대 해석의 존재를 함께 알려야 한다.** 이 문항의 학습 가치는 답 자체가 아니라 「‘만난다’는 등호 포함, ‘사이’는 순부등호」라는 표현-경계 대응을 익히는 데 있다.
**실측** `ax+2y+2a-2`에 A·B를 대입한 부호곱이 `<0`이면 -15, `<=0`이면 -21. 두 값 모두 전수 열거로 확인했다.

### 2-19 — m+n = 7 ⚠️ v2 오답 정정 (원문 오류 아님 — 정상 문제)
> O(0,0), A(7,7), B(-1,3), 직선 OB 위에 있고 **제2사분면**에 있는 점 C. △OAB=S₁, △OAC=S₂, S₂=3S₁. 직선 x+y-6=0이 △OAC를 m:n으로 분할.
> **v2 오류**: "B(-1,3)이 제2/3사분면 조건과 모순된다"고 판단해 문제 자체가 잘못됐다고 결론 내렸으나 오독임. 제2사분면 조건은 B가 아니라 **직선 OB 위의 점 C**에 걸린 조건이며, B(-1,3)은 그냥 주어진 고정점이라 모순이 전혀 없음. 정상적으로 풀리는 문제.
**풀이** ① S₁=△OAB = ½|x_A y_B - x_B y_A| = ½|21+7| = 14.
② C는 직선 OB 위 점이므로 C=t·(-1,3) (t>0이면 제2사분면). S₂=△OAC = ½|7·3t-(-t)·7| = 14t.
③ S₂=3S₁ → 14t=42 → t=3 → **C=(-3,9)**.
④ 확인: x+y-6=0에 C(-3,9)를 대입하면 -3+9-6=0 → **C는 이 직선 위에 정확히 있음**. 즉 x+y-6=0은 꼭짓점 C를 지나며, OA와 만나는 점 D를 구하면(OA를 t':1-t'로 매개화) D=(3,3) (OA를 **3:4**로 내분 — O에서 3/7 지점이라는 뜻이며, 내분비 3:7이 아니다).
⑤ 케비안 CD가 △OAC를 △ODC:△DAC = OD:DA = 3:4로 분할 (넓이 각각 18, 24, 합 42=S₂ 일치 확인).
**정답**: m:n=3:4 (서로소) → **m+n=7**.

## #3 원의 방정식 — 32문항 (SM2-15~25)

### 3-1 — r = 5

### 3-2 — 중심 (2,-1)

### 3-3 — a²+b² = 26
> (2,1), (6,5)를 잇는 선분을 빗변으로 하는 직각삼각형의 외접원이 (x-2)(x-6)+(y+a)(y+b)=0

**주의** (260901 정정) 원문 형식이 `(y+a)(y+b)`이므로 a는 -1이다(v3의 `a=1`은 부호 오류 — a²+b²=26은 우연히 불변).

### 3-4 — x² + (y-5)² = 25 , (x-8)² + (y-13)² = 169

**답 x² + (y-5)² = 25** 와 **(x-8)² + (y-13)² = 169** — 두 원 모두 조건을 만족하므로 둘 다 써야 한다.
**주의** (260901 정정) 원문이 요구하는 것은 「원의 방정식」이므로 중심·반지름만 쓰면 요구 형식 미달이다. v3에 있던 「하나만 쓰면 0.5점 감점」은 **삭제** — 이 부교재에는 배점·채점기준이 존재하지 않는다(자료 등급 2차, CLAUDE.md 원칙 6).

### 3-11 — a = 25 (넓이 625/39) ⚠️ v2 오답 정정 (a=625 → a=25)
> **v2 오류**: 넓이 계산(625/39)까지는 맞았으나, a²=625에서 제곱근을 빠뜨리고 a=625로 잘못 씀.

### 3-12 — -√3 < m < -2√5/5 또는 2√5/5 < m < √3
> 직선 y=mx+2가 두 원 x²+y²=1, x²+y²-6x-4y+9=0과 **모두 만나지 않도록** 하는 m의 범위
**풀이** ① 두 번째 원은 (x-3)²+(y-2)²=4 → 중심 (3,2), r=2. 첫 원은 중심 O, r=1. 직선을 mx-y+2=0으로 둔다.
② 첫 원과 만나지 않음: |2|/√(m²+1) > 1 → m²+1 < 4 → **m² < 3**.
③ 둘째 원과 만나지 않음: |3m-2+2|/√(m²+1) = 3|m|/√(m²+1) > 2 → 9m² > 4m²+4 → **m² > 4/5**.
④ 두 조건을 함께 → 4/5 < m² < 3 → **-√3 < m < -2√5/5 또는 2√5/5 < m < √3**.
**함정** 한쪽 원만 보고 끝내면 범위가 넓어진다. 두 부등식의 **교집합**이고, m의 부호 양쪽이 모두 살아 구간이 2개다.

### 3-13 — a+b = 4
> 원 x²+y²-4x-2y=m과 직선 x-y-3=0이 서로 다른 두 점 A, B에서 만난다. 정수 m의 최솟값 a, AB=6인 m의 값 b
**풀이** ① 원은 (x-2)²+(y-1)²=m+5 → 중심 (2,1), r=√(m+5) (m > -5).
② 중심과 직선의 거리 = |2-1-3|/√2 = 2/√2 = **√2**. 두 점에서 만나려면 r > √2 → m+5 > 2 → m > -3 → 정수 최솟값 **a = -2**.
③ AB=6이면 반현 3이므로 r² = 3² + (√2)² = 11 → m+5 = 11 → **b = 6**. ④ **a+b = 4**.
**함정** a는 "m > -3을 만족하는 정수의 최솟값"이지 -3이 아니다(등호면 접한다).

### 3-14 — 기울기의 합 = -9/4
> 원 x²+y²+2x=0에 접하고, 원 x²+y²-4x+6y+12=0의 넓이를 이등분하는 모든 직선의 기울기의 합
**풀이** ① 첫 원은 (x+1)²+y²=1 → 중심 (-1,0), r=1. 둘째 원은 (x-2)²+(y+3)²=1 → 중심 **(2,-3)**.
② 원의 넓이를 이등분하는 직선은 그 원의 **중심을 지난다** → 직선은 (2,-3)을 지난다: kx - y - 2k - 3 = 0.
③ 첫 원에 접함: |-k - 2k - 3|/√(k²+1) = 1 → 9(k+1)² = k²+1 → 8k² + 18k + 8 = 0 → 4k² + 9k + 4 = 0.
④ 근과 계수의 관계로 **합 = -9/4** (판별식 81-64 = 17 > 0이므로 실근 2개).
**함정** 수직선 x=2도 (2,-3)을 지나지만 중심 (-1,0)까지 거리가 3이라 접하지 않는다 — 기울기 없는 해가 없으므로 근과 계수의 관계를 그대로 쓸 수 있다.

### 3-15 — 접선의 길이 = 4
> (x-3)²+(y-5)²=9 밖의 점 (-1,2)에서 접선을 그을 때 접점까지의 거리
**풀이** 중심 (3,5)까지의 거리 d = √{(3+1)²+(5-2)²} = √25 = 5. 접선의 길이 = √(d² - r²) = √(25-9) = **4**.

### 3-16 — -9 < k < 1
> A(5,3), B(1,1)을 지름의 양 끝점으로 하는 원과 직선 y=2x+k가 서로 다른 두 점에서 만나는 k의 범위

### 3-17 — y = 2x + 3√5, y = 2x - 3√5
> x²+y²+2x+4y-4=0에 접하고 기울기가 2인 직선
**풀이** 원은 (x+1)²+(y+2)²=9 → 중심 (-1,-2), r=3. y=2x+c → 2x-y+c=0.
|2(-1)-(-2)+c|/√5 = |c|/√5 = 3 → c = ±3√5 → **y = 2x ± 3√5**.
**함정** 두 개를 모두 써야 한다 — 접선은 원의 양쪽에 하나씩 생긴다.

### 3-18 — a²b² = 4
> 원 x²+y²=5 위의 점 (a,b)에서의 접선이 직선 y = -x/2 + 1과 수직
**풀이** ① 접선은 ax+by=5이고 기울기는 -a/b.
② 수직 조건: (-a/b)·(-1/2) = -1 → a = -2b.
③ a²+b²=5 → 4b²+b²=5 → b²=1, a²=4 → **a²b² = 4**.
**함정** (a,b)는 (-2,1)과 (2,-1) 두 개지만 a²b²은 둘 다 4로 같다.

### 3-19 — m₁m₂ = -1
> 점 (3,-1)에서 원 x²+y²=5에 그은 두 접선의 기울기의 곱
**풀이** y+1 = m(x-3) → mx - y - 3m - 1 = 0. |−3m−1|/√(m²+1) = √5 → (3m+1)² = 5(m²+1)
→ 4m² + 6m - 4 = 0 → 2m² + 3m - 2 = 0 → **m₁m₂ = -2/2 = -1** (두 접선이 서로 수직이라는 뜻).

### 3-20 — 넓이 = 50/3
> y=3x-1과 평행하고 **제2사분면에서** 원 x²+y²=10에 접하는 직선 l과 두 축으로 둘러싸인 부분의 넓이
**풀이** ① y=3x+c → 3x-y+c=0, |c|/√10 = √10 → c = ±10.
② 접점은 원점에서 내린 수선의 발 (-3c/10, c/10). c=10이면 **(-3,1)** 로 제2사분면 ✓, c=-10이면 (3,-1)로 제4사분면 ✗.
③ l: y = 3x+10 → x절편 -10/3, y절편 10 → 넓이 = ½·(10/3)·10 = **50/3**.
**함정** c의 부호를 정하는 것은 "제2사분면" 조건이다 — 접점을 실제로 구해야 가려진다.

### 3-21 — 반지름 = √10/2
> 두 원 x²+y²-4x=0, x²+y²-6x-2y+8=0의 교점과 (1,0)을 지나는 원의 반지름
**풀이** ① 원족 (x²+y²-4x) + k(x²+y²-6x-2y+8) = 0에 (1,0) 대입 → -3 + 3k = 0 → k=1.
② 더하면 2x²+2y²-10x-2y+8=0 → x²+y²-5x-y+4=0 → (x-5/2)²+(y-1/2)² = 25/4 + 1/4 - 4 = **5/2**.
③ 반지름 = √(5/2) = **√10/2**.

### 3-22 — a²+b² = 7
> 두 원 x²+y²=1, x²+(y-2)²=4의 공통접선이 y=ax+b
**풀이** ① 중심 O(r=1)과 (0,2)(r=2), 중심거리 2이고 2-1 < 2 < 2+1이라 **두 원은 두 점에서 만난다** → 공통접선은 2개(공통외접선)뿐이다.
② ax-y+b=0에 대해 |b|/√(a²+1) = 1, |b-2|/√(a²+1) = 2 → |b-2| = 2|b|.
③ b>0이면 b=2/3이 나오지만 √(a²+1)=2/3에서 a² = -5/9 < 0이라 모순. b<0이면 2-b = -2b → **b = -2**, √(a²+1) = 2 → **a = ±√3**.
④ **a²+b² = 3+4 = 7**.
**함정** |b-2| = 2|b|를 부호 나눔 없이 풀면 허해를 답으로 쓰게 된다.

### 3-23 — a = -√3/3
> 원 (x-2)²+y²=4 위의 두 점 O, A에 대해 선분 OA의 수직이등분선이 y = ax + (2/3)√3 (O는 원점)
**풀이** ① 원점은 이 원 위의 점이다(4+0=4 ✓).
② **현의 수직이등분선은 반드시 원의 중심을 지난다** → 직선이 중심 (2,0)을 지난다.
③ 0 = 2a + (2/3)√3 → a = -√3/3.
**함정** O가 원 위의 점이라는 것과 "수직이등분선 → 중심 통과"를 못 보면 손댈 곳이 없다.

### 3-24 — 개수 = 12
> 원 (x-4)²+(y-3)²=9 위의 점 P에 대하여 선분 OP의 길이가 **정수**가 되도록 하는 P의 개수
**풀이** ① 중심 C(4,3), |OC| = 5, r = 3.
② P가 원 위를 돌 때 OP는 **[|OC|-r, |OC|+r] = [2, 8]** 의 값을 모두 한 번씩 훑는다.
③ 정수값은 2,3,4,5,6,7,8의 7개. 이 중 **끝값 2와 8은 P가 1개씩**(중심선 위의 **가까운 점·먼 점**), **사이의 3,4,5,6,7은 각각 2개씩**(원과 동심원 O의 교점이 2개).
④ 1 + 5×2 + 1 = **12**.
**함정** "정수값 7개"에서 멈추면 7이 답이 된다. 각 값마다 점이 **몇 개**인지가 문제이고, 끝값만 1개다.

### 3-25 — ab = 6
> P(3,2)에서 원 x²+y²=1에 그은 두 접선의 접점 A, B를 지나는 직선이 ax+by=1
**풀이** 원 x²+y²=r² 밖의 점 (x₁,y₁)에서 그은 두 접선의 접점을 지나는 직선(**접현**)은 x₁x + y₁y = r²이다.
→ 3x + 2y = 1 → a=3, b=2 → **ab = 6**.
**함정** 접점을 각각 구해 두 점을 지나는 직선을 세울 필요가 없다 — 접현 공식이 바로 답이다.

### 3-26 — 최솟값 = √7/4
> 원 x²+(y-2)² = 7/16 위의 점 P와 포물선 y=x² 위의 점 Q에 대하여 PQ의 최솟값
**풀이** ① 원의 중심 C(0,2), r = √(7/16) = √7/4.
② C와 포물선 위 점 (x, x²)의 거리²을 u = x² (≥0)로 두면 u + (u-2)² = u² - 3u + 4, 최소는 u = 3/2에서 **7/4** → 거리 = √7/2.
③ PQ의 최솟값 = (C까지의 최소거리) − r = √7/2 − √7/4 = **√7/4**.
**함정** u = x² ≥ 0 조건을 확인해야 한다(여기서는 u=3/2가 양수라 통과).

### 3-27 — k² = 72
> 원 밖의 점 A에서 원 (x-5)²+(y-4)²=9에 그은 두 접선의 접점 B, C. BC = 2√6일 때 삼각형 ABC의 넓이가 k
**풀이** ① 중심을 O′, r=3, d = AO′라 하면 **접현 BC의 길이 = 2r√(d²-r²)/d**.
② 2·3·√(d²-9)/d = 2√6 → 9(d²-9) = 6d² → 3d² = 81 → **d = 3√3**.
③ BC는 중심에서 거리 r²/d = 9/(3√3) = √3 인 위치에 있으므로, **A에서 BC까지의 거리 = d − r²/d = 3√3 − √3 = 2√3**.
④ k = ½·BC·(A에서 BC까지 거리) = ½·2√6·2√3 = 2√18 = **6√2** → **k² = 72**.
**함정** A에서 BC까지의 거리를 d로 착각하면 안 된다 — BC는 A와 중심 사이에 있다.

### 3-28 — a+b = 6
> 원 (x-4)²+y²=16 위의 점 A(4,4)와 **제4사분면**의 점 P에 대하여 삼각형 PAO의 넓이가 최대일 때 P의 x좌표가 a+b√2
**풀이** ① 이 원은 원점 O를 지난다(16=16 ✓). 밑변 OA는 고정이고 직선 OA는 **y = x**.
② P = (4+4cosθ, 4sinθ)에 대해 P와 직선 x−y=0의 거리 = |4 + 4cosθ − 4sinθ|/√2 = |4 + 4√2·cos(θ+45°)|/√2.
③ 최대는 cos(θ+45°) = 1, 즉 θ = −45°일 때 → **P = (4+2√2, −2√2)** — x>0, y<0이므로 제4사분면 ✓.
④ a = 4, b = 2 → **a+b = 6**.
**함정** θ = 135°(반대쪽 최대)의 점은 **(4-2√2, 2√2) ≈ (1.17, 2.83)** 으로 **제1사분면**이다 — 제2사분면이 아니다. 탈락 사유는 「제4사분면이 아니라서」다.

### 3-29 — 기울기 = 5/12
> 원 (x-2)²+(y-6)²=4가 y축과 만나는 점 A. 두 원 (x+2)²+y²=4, (x-2)²+(y-6)²=4에 동시에 접하는 직선 중 **선분 OA와 한 점에서만 만나는** 직선의 기울기
**풀이** ① 중심 (2,6)에서 y축까지 거리가 2 = r이므로 이 원은 y축에 **접한다** → A(0,6), 선분 OA는 y축 위의 0 ≤ y ≤ 6 구간.
② 두 원은 반지름이 같고(2) 중심거리 √(4²+6²) = 2√13 > 4이라 공통접선이 4개다.
③ **공통외접선 2개**: 중심선과 평행(기울기 3/2), y = (3/2)x + c 에서 |c-3| = √13 → c = 3±√13 ≈ 6.61, −0.61. y축과의 교점이 각각 6보다 크고 0보다 작으므로 **선분 OA를 만나지 않는다**.
④ **공통내접선 2개**: 중심의 중점 M(0,3)을 지난다. M은 선분 OA 위의 점이다.
   - **x = 0 (y축 자체)**: 두 중심까지의 거리가 모두 2라 공통접선이 맞지만, **선분 OA를 통째로 포함**하므로 "한 점에서만 만난다"에 어긋난다 → 탈락.
   - y = mx+3: |−2m+3|/√(m²+1) = 2 → (3−2m)² = 4(m²+1) → 9 − 12m = 4 → **m = 5/12**.
⑤ **기울기 = 5/12**.
**함정** y축 x=0이 공통접선이라는 점을 놓치면 "왜 두 개가 아니라 하나인가"를 설명할 수 없다. 배제 근거는 **접점의 개수가 아니라 선분 OA와의 교점 개수**다.

### 3-30 — AB = √77
> 두 원 O: x²+y²=25, O′: (x-9)²+y²=9에 **제1사분면에서** 동시에 접하는 접선 l의 두 접점 A, B에 대하여 AB
**풀이** ① 중심거리 d = 9, 반지름 5와 3. 5+3 = 8 < 9이므로 두 원은 **서로 밖에 있다**.
② 접점이 둘 다 제1사분면(중심선 x축의 같은 쪽) → **공통외접선**.
③ 공통외접선의 접점 사이 거리 = √(d² − (r₁−r₂)²) = √(81 − 4) = **√77**.
**함정** 공통내접선 공식 √(d²−(r₁+r₂)²) = √17을 쓰면 안 된다 — 내접선은 두 접점이 중심선의 반대쪽에 생긴다.

### 3-31 — AB = 3√3
> 두 원 C₁: x²+(y-2)²=1, C₂: x²+(y+4)²=4의 공통접선 l이 **제2사분면에서 C₁**과 만나는 점 A, **제4사분면에서 C₂**와 만나는 점 B
**풀이** ① 중심 (0,2)와 (0,-4), 중심거리 d = 6. r₁+r₂ = 3 < 6이라 두 원은 서로 밖에 있다.
② A는 제2사분면(x<0), B는 제4사분면(x>0) — 두 접점이 중심선(y축)의 **반대쪽**에 있으므로 **공통내접선**이다.
③ AB = √(d² − (r₁+r₂)²) = √(36 − 9) = √27 = **3√3**.
**함정** 3-30과 짝을 이루는 문제다. **접점이 중심선의 같은 쪽이면 외접선, 반대쪽이면 내접선** — 사분면 조건이 그것을 지정한다.

### 3-32 — r = 3
> 두 원 O: x²+y²=1, O′: (x-8)²+(y-6)²=r²의 공통접선 l이 **제4사분면에서 O**와 만나는 점 A, **제1사분면에서 O′**와 만나는 점 B (B의 x좌표 < 8), AB = 2√21
**풀이** ① 중심거리 d = √(8²+6²) = 10. 중심선 OO′는 직선 3x − 4y = 0이다.
② A는 제4사분면이므로 3A_x − 4A_y > 0 (중심선의 한쪽). B는 제1사분면이면서 x좌표가 8보다 작으므로 중심 (8,6)에서 볼 때 **반대쪽**이다 → 두 접점이 중심선의 반대쪽 → **공통내접선**.
③ AB = √(d² − (r₁+r₂)²) → 84 = 100 − (1+r)² → (1+r)² = 16 → **r = 3** (r > 0).
**검산** 수치로 r=3의 내접선을 실제로 구하면 A ≈ (0.870, −0.493)(제4사분면 ✓), B ≈ (5.390, 7.480)(제1사분면, x<8 ✓), AB = 9.16515 = 2√21 ✓. 반면 외접선 해석 r=5는 같은 사분면 조건에서 AB = 8이 되어 조건과 어긋난다.
**함정** 외접선으로 보면 (r−1)² = 16 → r = 5가 나온다. **사분면 조건이 내·외접선을 결정한다**는 것이 이 문제의 핵심이다.

### 4-1 — a+b = 6
> (1,1)을 (2,-3)으로 옮기는 평행이동에 의해 (a,b)가 (-3,6)으로 옮겨진다
**풀이** 평행이동은 (x+1, y-4). (a+1, b-4) = (-3, 6) → a = -4, b = 10 → **a+b = 6**.

### 4-2 — a+b = 1
> A(-1,3) B(5,b) C(a,7)의 무게중심이 (x,y)→(x-2,y-3)에 의해 원점으로 옮겨진다
**풀이** ① 무게중심 G = ((-1+5+a)/3, (3+b+7)/3) = ((a+4)/3, (b+10)/3).
② 이동 후 원점 → G = **(2, 3)** → (a+4)/3 = 2 → a = 2, (b+10)/3 = 3 → b = -1 → **a+b = 1**.
**함정** "원점으로 옮겨진다"는 G가 원점이라는 뜻이 아니라 **G를 (+2,+3)만큼 되돌린 점**이 원점이라는 뜻이다.

### 4-3 — ab = 3/2
> y=ax+b를 x축 방향 2, y축 방향 -1 평행이동한 직선이 y=-2x+1과 **y축 위에서 수직으로** 만난다
**풀이** ① 이동한 직선: y = a(x-2) + b - 1 = ax - 2a + b - 1.
② 수직 → a·(-2) = -1 → **a = 1/2**.
③ y축 위에서 만난다 → y절편이 같다: -2a + b - 1 = 1 → -1 + b - 1 = 1 → **b = 3**. ④ **ab = 3/2**.

### 4-4 — a = 9/2
> 평행이동 (x+a, y-1)에 의해 2x+y-2=0이 옮겨진 직선 l과 두 축이 만드는 넓이가 25 (a>0)
**풀이** ① 이동한 직선은 원식의 x에 x-a, y에 y+1을 대입 → 2(x-a) + (y+1) - 2 = 0 → **2x + y - (2a+1) = 0**.
② x절편 (2a+1)/2, y절편 2a+1 → 넓이 = ½ · |(2a+1)/2| · |2a+1| = (2a+1)²/4 = 25 → (2a+1)² = 100.
③ 2a+1 = ±10 → a = 9/2 또는 -11/2. a > 0이므로 **a = 9/2**.
**함정** 도형을 (+a, -1) 옮기면 식에는 **(x-a), (y+1)** 을 대입한다 — 부호를 반대로 넣기 쉽다.

### 4-5 — a = 12
> y=x²-2x를 y=x²-10x+20으로 옮기는 평행이동에 의해 x-2y+a=0이 옮겨진 직선 l이 원점을 지난다
**풀이** ① y = (x-1)² - 1 → 꼭짓점 (1,-1). y = (x-5)² - 5 → 꼭짓점 (5,-5). 평행이동은 **(+4, -4)**.
② 직선에 적용: (x-4) - 2(y+4) + a = 0 → x - 2y - 12 + a = 0.
③ 원점 통과 → -12 + a = 0 → **a = 12**.

### 4-6 — a+b+c = 5
> x²+y²+10x-8y+25=0을 (x+a, y+b)로 옮겼더니 x²+y²+10y+c=0과 겹쳐진다
**풀이** ① 처음 원: (x+5)²+(y-4)² = 25+16-25 = **16** → 중심 (-5,4), r=4.
② 나중 원: x²+(y+5)² = 25 - c → 중심 (0,-5), r = √(25-c).
③ 겹쳐지려면 반지름이 같아야 한다: 25 - c = 16 → **c = 9**.
④ 중심의 이동: (-5+a, 4+b) = (0,-5) → **a = 5, b = -9**. ⑤ **a+b+c = 5 - 9 + 9 = 5**.

### 4-7 — a = 4
> x²+y²=4를 x축 방향으로 a만큼 옮기면 3x-4y-2=0과 접한다 (a>0)
**풀이** 중심 (a,0), r=2. |3a-2|/5 = 2 → |3a-2| = 10 → a = 4 또는 -8/3 → **a = 4**.

### 4-8 — b-a = 13
> x²+y²+6x-2y+a=0을 (b, -2b)만큼 옮긴 원이 두 축에 동시에 접하고 중심이 제2사분면
**풀이** ① 처음 원: (x+3)²+(y-1)² = 10-a → 중심 (-3,1), r = √(10-a).
② 옮긴 중심: (-3+b, 1-2b). 두 축에 접하고 제2사분면 → 중심은 **(-r, r)** 꼴.
③ -3+b = -r, 1-2b = r → 두 식을 더하면 -2 - b = 0 → **b = -2**, 이때 r = 5.
④ 10 - a = 25 → **a = -15** → **b - a = -2 + 15 = 13**.
**함정** 제2사분면이므로 |중심의 x| = |중심의 y| = r을 쓸 때 **x는 음수, y는 양수**로 부호를 고정해야 한다.

### 4-9 — 1/2 ≤ k ≤ 9/2
> x²+y²=2를 (-1, k)만큼 옮긴 원이 직선 2x+2y-3=0과 만나는 k의 범위
**풀이** ① 옮긴 원: (x+1)²+(y-k)² = 2 → 중심 (-1, k), r = √2.
② 만난다 → 중심과 직선의 거리 ≤ r: |-2 + 2k - 3|/√8 ≤ √2 → |2k-5| ≤ √2·2√2 = 4.
③ -4 ≤ 2k-5 ≤ 4 → **1/2 ≤ k ≤ 9/2**.
**함정** "만난다"는 접하는 경우를 포함하므로 **등호를 넣는다**.

### 4-10 — a+b의 최솟값 = -2
> (a-2, b+6)을 x축 대칭 후 y=x 대칭한 점이 제2사분면에 있을 때 정수 a, b에 대한 a+b의 최솟값
**풀이** ① x축 대칭: (a-2, -(b+6)). ② y=x 대칭(좌표 교환): **(-(b+6), a-2)**.
③ 제2사분면 → x < 0, y > 0: -(b+6) < 0 → b > -6 → 정수 최소 **b = -5** / a - 2 > 0 → a > 2 → 정수 최소 **a = 3**.
④ 최솟값 = 3 + (-5) = **-2**.
**함정** 부등호에 등호가 없으므로 b = -6, a = 2는 쓸 수 없다(축 위가 되어 사분면이 아니다).

### 4-11 — P₄₉ = (3, 2)
> P₁(3,2)에서 x축 대칭 → 원점 대칭을 번갈아 반복할 때 P₄₉
**풀이** P₁(3,2) → P₂(3,-2) → P₃(-3,2) → P₄(-3,-2) → P₅(3,2) = P₁.
**주기가 4**이고 49 = 4·12 + 1이므로 **P₄₉ = P₁ = (3, 2)**.
**함정** 두 대칭이 번갈아 나오므로 주기는 2가 아니라 4다.

### 4-12 — 최솟값 = 2√10
> 직선 y=x 위의 점 P와 A(0,6), B(4,6)에 대하여 AP+BP의 최솟값
**풀이** ① A(0,6)은 6 > 0, B(4,6)은 6 > 4이므로 **둘 다 y=x의 같은 쪽(위쪽)** 이다.
② A를 y=x에 대하여 대칭이동 → A′(6, 0). AP = A′P이므로 AP+BP = A′P + PB ≥ **A′B**.
③ A′B = √{(4-6)² + (6-0)²} = √40 = **2√10**.
**함정** 두 점이 같은 쪽에 있어야 대칭이동이 필요하다 — 반대쪽이면 그냥 AB가 답이다.

### 4-13 — 넓이 = 9/4
> x축 위의 점 P에 대하여 AP+BP가 최소일 때 삼각형 ABP의 넓이 (A(2,1), B(5,3))
**풀이** ① A, B 모두 x축 위쪽. A를 x축 대칭 → A′(2,-1). 최소는 P가 **선분 A′B와 x축의 교점**일 때.
② A′(2,-1) → B(5,3)에서 y=0이 되는 지점: 매개변수 t = 1/4 → **P(11/4, 0)**.
③ 넓이 = ½|(5-2)(0-1) - (3-1)(11/4-2)| = ½|-3 - 3/2| = **9/4**.

### 4-14 — 기울기 = -2
> (-1,0)을 지나는 직선을 y축 방향 1만큼 평행이동한 후 x축 대칭했더니 (1,3)을 지난다
**풀이** ① 처음 직선 y = m(x+1). ② y축 방향 +1 → y = m(x+1) + 1.
③ x축 대칭(y → -y) → -y = m(x+1) + 1 → y = -m(x+1) - 1.
④ (1,3) 대입: 3 = -2m - 1 → **m = -2**.

### 4-15 — a-2b = 20
> (2k+1)x + (k+1)y - 4 = 0을 원점 대칭한 직선이 k에 관계없이 항상 (a,b)를 지난다
**풀이** ① 원점 대칭(x → -x, y → -y): -(2k+1)x - (k+1)y - 4 = 0 → **(2k+1)x + (k+1)y + 4 = 0**.
② k에 대해 정리: k(2x + y) + (x + y + 4) = 0. k에 관계없이 성립하려면 2x+y = 0이고 x+y+4 = 0.
③ 연립 → **(a, b) = (4, -8)** → a - 2b = 4 + 16 = **20**.
**함정** 원점 대칭을 하면 상수항의 부호만 바뀐다 — 정점도 원래 직선의 정점 (-4, 8)의 원점 대칭이다.

### 4-16 — 최솟값 = 6√2 + 2√5
> AB=5, BC=4인 직사각형. P는 AD의 중점, S는 CD를 1:4로 내분. Q는 AB 위, R은 BC 위. 사각형 PQRS의 둘레의 최솟값
**풀이** ① 도표(`p17.png`)대로 좌표를 잡는다 — **A(0,5), B(0,0), C(4,0), D(4,5)**. AB는 왼쪽 세로변(=5), BC는 아래 가로변(=4), AD는 위 가로변(=4), CD는 오른쪽 세로변(=5) ✓.
② P는 AD의 중점 → **P(2,5)**. S는 CD를 C에서 1:4로 나눈 점 → **S(4,1)** (도표에서 S가 C 가까이 있는 것과 일치).
③ 둘레 = PQ + QR + RS + **SP**이고 SP는 고정: SP = √{(4-2)²+(1-5)²} = √20 = **2√5**.
④ PQ+QR+RS는 P를 직선 AB(x=0)에 대칭 → **P′(-2,5)**, S를 직선 BC(y=0)에 대칭 → **S′(4,-1)** 하면
   PQ+QR+RS = P′Q + QR + RS′ ≥ **P′S′** = √{(4+2)² + (-1-5)²} = √72 = **6√2**.
⑤ 최솟값 = **6√2 + 2√5**.
**검산** 등호는 Q, R이 선분 P′S′ 위에 놓일 때다. 직선 P′S′은 y = 3 - x이므로 Q(0,3)은 AB 위(0≤y≤5) ✓, R(3,0)은 BC 위(0≤x≤4) ✓ — 두 점 모두 변 안에 있으므로 최솟값이 실제로 달성된다.
**함정** SP는 Q, R과 무관하므로 **최소화 대상이 아니다**. 네 변을 모두 대칭이동으로 펴려 하면 틀린다.

### 4-17 — ab = -8
> A(0,1), 원 (x-4)²+(y-3)²=4. x축 위의 점 P와 원 위의 점 B에 대하여 AP+BP의 최솟값이 a+b√2
**풀이** ① 원의 중심 C(4,3), r=2. **BP ≥ PC − r** 이므로 AP + BP ≥ AP + PC − 2.
② AP+PC의 최소는 A를 x축 대칭한 **A′(0,-1)** 을 써서 A′C = √{(4-0)² + (3+1)²} = √32 = **4√2**.
③ 최솟값 = 4√2 − 2 → a = **-2**, b = **4** → **ab = -8**.
**함정** a는 유리수부이므로 -2다. `a+b√2` 꼴에 맞추려면 상수항을 앞에 두어야 한다.

### 4-18 — a+b = 4
> y=x가 원 C₁: x²+y²+ax+by=0의 넓이를 이등분한다. C₁을 원점 대칭한 도형을 C₂라 할 때 두 중심 사이의 거리가 2√2 (a, b는 양수)
**풀이** ① C₁의 중심은 (-a/2, -b/2). 넓이를 이등분 → y=x가 중심을 지난다 → -b/2 = -a/2 → **a = b**.
② C₂의 중심은 원점 대칭 → (a/2, b/2). 두 중심 사이의 거리 = √(a² + b²) = 2√2 → a² + b² = 8.
③ a = b이므로 2a² = 8 → a = 2(양수) → b = 2 → **a+b = 4**.

### 4-19 — A(19/5, -2/5)
> 점 A를 직선 2x-y-2=0에 대하여 대칭이동한 점이 B(-1,2)
**풀이** 대칭이동은 두 번 하면 제자리이므로 **A는 B를 같은 직선에 대칭이동한 점**이다.
법선 n=(2,-1), |n|²=5. B에서의 값 2(-1)-2-2 = -6 → A = B - (2·(-6)/5)(2,-1) = (-1,2) + (12/5)(2,-1) = **(19/5, -2/5)**.
**검산** 중점 (7/5, 4/5)를 직선에 대입 → 14/5 - 4/5 - 2 = 0 ✓, AB의 방향 (24/5, -12/5) ∥ (2,-1) ✓.

### 4-20 — 넓이 = 1/4
> A(2,3), B(4,-1)이 직선 l에 대하여 대칭일 때 l과 두 축으로 둘러싸인 부분의 넓이
**풀이** ① 두 점이 l에 대해 대칭 → l은 **AB의 수직이등분선**.
② 중점 (3,1), AB의 기울기 = (-1-3)/(4-2) = -2 → l의 기울기 = **1/2**.
③ l: y - 1 = ½(x-3) → **x - 2y - 1 = 0** → x절편 (1,0), y절편 (0,-1/2).
④ 넓이 = ½·1·½ = **1/4**.

### 4-21 — a = 11/2
> A(4,a), B(2,1)을 y=x에 대칭한 점 A′, B′. 직선 AB와 A′B′의 교점 P. 삼각형 APA′와 BPB′의 넓이비가 9:4 (a>4)
**풀이** ① A′(a,4), B′(1,2). AA′와 BB′는 둘 다 y=x에 수직이므로 **AA′ ∥ BB′**.
② 따라서 삼각형 APA′와 BPB′는 **닮음**이고, 넓이비 = (AA′ : BB′)².
③ AA′ = |a-4|√2, BB′ = |2-1|√2 = √2 → 넓이비 = (a-4)² = 9/4 → a - 4 = 3/2 (a>4) → **a = 11/2**.
**함정** 넓이비 9:4는 **길이비 3:2**다.

### 4-22 — g(x, y) = f(x-5, -y-1) = 0
> 두 방정식 f(x,y)=0, g(x,y)=0이 나타내는 도형이 그림과 같을 때 g를 f로 나타내시오
**풀이** ① 도표(`p18.png`) 실측 — **f**: 세 꼭짓점 (-3,0), (-1,0), (-1,2)인 직각삼각형(직각은 (-1,0), 가로변은 왼쪽으로, 세로변은 **위로**). **g**: (2,-1), (4,-1), (4,-3)인 직각삼각형(직각은 (4,-1), 가로변은 왼쪽으로, 세로변은 **아래로**).
② 세로변의 방향만 뒤집혔으므로 먼저 **x축에 대하여 대칭이동**(y → -y): (-3,0), (-1,0), (-1,-2).
③ 이어서 **x축 방향 +5, y축 방향 -1 평행이동**: (2,-1), (4,-1), (4,-3) → g와 정확히 일치 ✓.
④ 도형을 x축 대칭한 뒤 (+5, -1) 옮긴 결과이므로 식에서는 **x에 x-5를, y에 -(y+1)을 대입**한다:
   **g(x, y) = f(x-5, -y-1) = 0**.
**검산** g의 꼭짓점을 대입하면 (2,-1) → f(-3, 0), (4,-1) → f(-1, 0), (4,-3) → f(-1, 2) — f의 세 꼭짓점과 3/3 일치.
**함정** 이동과 대입은 **반대 부호**다. 도형을 오른쪽으로 5 옮기면 식에는 x-5를 넣는다.

### 4-23 — (x+2)² + y² = 1
> 원 (x+4)²+(y-2)²=1을 직선 y=3x+4에 대칭이동한 후 y축에 대칭이동한 도형의 방정식
**풀이** ① 반지름은 대칭이동으로 변하지 않으므로 **r = 1** 고정. 중심 (-4, 2)만 옮기면 된다.
② 직선을 3x - y + 4 = 0으로 두면 법선 n = (3,-1), |n|² = 10. 중심에서의 값 = 3(-4) - 2 + 4 = **-10**.
   대칭점 = (-4,2) - (2·(-10)/10)(3,-1) = (-4,2) + (6,-2) = **(2, 0)**.
③ y축 대칭 → **(-2, 0)**. ④ **(x+2)² + y² = 1**.
**검산** (-4,2)와 (2,0)의 중점 (-1,1)은 y=3x+4 위에 있고(3(-1)+4 = 1 ✓), 두 점을 잇는 방향 (6,-2) ∥ (3,-1) = 법선 ✓.
