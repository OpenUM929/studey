# extracted/ — 기출 추출물 보관소

> 원본(`origin_data/`, 루트 `test/`)에서 **텍스트·이미지로 변환한 2차 사본**만 둔다.
> 분석·출제 시 이 폴더를 읽는다. 원본은 카탈로그 구축·갱신 시에만 연다.
> 유형 분석의 정본은 [`../analysis/catalog/`](../analysis/catalog/)이며, 이 폴더는 그 **근거 자료**다.

## 폴더 구조 (260825 재구성)

```
extracted/
├── README.md            ← 이 파일 (규칙)
├── INDEX.md             ← 자료 대장: 연도×회차×과목 매트릭스, 파일 위치·상태
├── <연도>/
│   ├── 중간/
│   │   ├── <과목>.txt   ← 고사원안 전문 (HWP→텍스트, 표보존본)
│   │   ├── 정답*.txt    ← 정답·배점표
│   │   └── pages/       ← 스캔 페이지 렌더가 필요한 경우
│   └── 기말/            ← 동일 구조
├── 수행평가/             ← 수행평가 자료 전용 (규칙은 하위 README)
└── _archive/            ← 폐기 예정·불량 파일 격리소 (분석 금지)
    ├── hwp_표소실/       ← 구 hwp/: 표가 소실된 1차 HWP 변환본 → 분석 기준 아님
    ├── hwphtml_test/     ← HTML 변환 실험 산출물
    └── 불량파일/          ← 빈 스텁·페이지 마커만 있는 파일
```

- 과목 폴더명·파일명은 **약칭 통일**: `국어 수학 영어 통합과학 통합사회 한국사`
  (원본 과목명 공통국어1·공통수학1 등과의 대응은 `INDEX.md` 참조)
- 시험 식별자 규칙: `<연도>-<학기><중간|기말>-<과목약자>` (예: `2026-1중간-수학`)
  — [`../analysis/EXTRACTION_LOG.md`](../analysis/EXTRACTION_LOG.md)와 동일한 키를 쓴다.

## 새 자료가 도착하면 (등록 절차 — 260825 개정)

> ⚠️ **이 폴더는 레거시 동결** — 신규 자료는 이곳에 넣지 않는다. 도착 자료는 `origin_data/_inbox/` 에 두고
> 정제 파이프라인(PRD output/260825/260825_01 §4)에 따라 `corpus/<코퍼스ID>/` 로 간다.

1. [`../analysis/EXTRACTION_LOG.md`](../analysis/EXTRACTION_LOG.md)에서 동일 시험 기존 등록 여부 확인 (중복 방지).
2. (레거시 보완분에 한해) 이 폴더의 `<연도>/<중간|기말|수행평가>/` 아래 배치.
   - 수행평가는 `수행평가/<연도>_<학기>_<과목>_<종류>` 명명 — 하위 `수행평가/README.md` 참조.
3. `EXTRACTION_LOG.md`에 행 추가 (append-only). 상태 흐름: `미착수` → `추출완료` → `분석완료`
   (신규 코드: arrived → normalized → extracted → analyzed).
4. `INDEX.md` 매트릭스 셀 갱신 (❌ → 실제 상태).

## 주의

- `_archive/` 는 분석·출제 근거로 **쓰지 않는다.**
- 2026 스캔(`2026/*/pNN.png`)은 학생 필기가 포함된 **응시본**이다. 고사원안이 아니므로
  배점·문항 구조 판독 시 오답분석 문서([`../analysis/student/`](../analysis/student/))와 대조한다.
- 2024·2025 `수학.txt`는 **수식 개체가 소실**되어 구조 참고용이다(⚠️ 표기). 수학 정밀 근거는
  2026 스캔 + 부교재다. ([`../analysis/catalog/math1.md`](../analysis/catalog/math1.md) 머리말 참조)
