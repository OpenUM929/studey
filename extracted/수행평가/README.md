# 수행평가/ — 수행평가 자료 전용 구역

> **현황: 미확보 (260825).** 고사반영 비율이 **중간30 + 기말30 + 수행40** 으로
> 수행평가가 단일 축 중 가장 무겁지만, 근거 자료가 한 건도 없다.
> 자료 도착 즉시 아래 규칙으로 등록한다.

## 배치·명명 규칙

```
수행평가/
└── <연도>_<학기>/
    └── <과목약자>_<종류코드>_<제목>.<원본확장자>
```

- 과목약자: `국어 수학 영어 통합과학 통합사회 한국사` (extracted/ 전체 통일 약칭)
- **종류코드** (등록 시 하나 지정):

| 코드 | 종류 | 예시 |
|------|------|------|
| `RPT` | 보고서·과제물 | 탐구보고서, 독서 과제 |
| `PRF` | 수행 활동·실습 | 실험 보고서, 발표 |
| `QZ`  | 쪽지시험·형성평가 | 단원 쪽지시험 (지필은 아님) |
| `PRJ` | 프로젝트·모둠과제 | 조사 발표, 포스터 |
| `ETC` | 기타 | 평가 계획서, 루브릭 등 |

- 예: `2026_1학기/통합과학_PRF_실험보고서_밀도측정.pdf`

## 등록 절차

1. [`../analysis/EXTRACTION_LOG.md`](../../analysis/EXTRACTION_LOG.md)에 행 추가 —
   시험 식별자는 `<연도>-<학기>수행-<과목약자>` (예: `2026-1수행-통과`)
2. 스캔이면 `pages/` 하위에 pNN.png 렌더 (기존 관행 준수)
3. [`../INDEX.md`](../INDEX.md) 매트릭스의 수행평가 행 갱신

## 분석 시 유의

- 수행평가는 **교사별·반별로 형식 편차가 크다.** 유형 카탈로그에 넣을 때는
  상태 `검증` 대신 **회차·담당 교사를 반드시 병기**한다.
- 채점 루브릭이 함께 확보되면 원본 옆에 `_루브릭` 접미 파일로 보관 —
  서술형 채점 조건([공통유형 C-05](../../analysis/catalog/공통유형.md)) 재현의 직접 근거가 된다.
